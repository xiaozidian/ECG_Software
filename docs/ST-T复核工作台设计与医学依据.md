# ST‑T 复核工作台设计与医学依据

更新日期：2026-08-24
适用版本：CardioInsight Holter 0.12.x 研究演示版

## 1. 功能定位

ST‑T 页面定位为“候选筛查与医生人工复核工作台”，不是自动缺血诊断器。当前版本支持：

- 按全天心率趋势定位真实原始波形；
- 普通视图选择 1–3 条导联，双击或按 `F` 进入全屏 12 导联复核；
- 手工拖动或用按钮微调 ISO、J 点，并选择 J、J+60 ms 或 J+80 ms；
- 显示测量点相对 ISO 的设备原始单位差值；
- 将“无法判读、未见明确动态改变、ST 段压低/抬高候选、T 波形态异常候选、非特异性改变、伪差或体位改变”等医生描述保存为人工标注；
- 独立展示源报告中的 ST‑T 文字线索，并明确它不是本软件重新判定的结果。

当前数据未完成电压增益计量溯源、导联接法核验、ST 分析滤波验证、信号质量算法和 J 点自动定位验证，因此：

- 不输出病例 ST 的 mV 数值；
- 不生成自动 ST‑T 事件队列；
- 不把源报告中的数值当成本软件测量值；
- 不诊断或排除心肌缺血、急性冠脉综合征、心肌梗死。

## 2. 测量方法

### 2.1 动态心电 / 连续监测

动态心电常以稳定 PR/PQ 段或个体稳定片段作为等电位参考，并在 J 点之后测量 ST 偏移。连续监测中，J+60 ms 是较稳妥的默认复核点；J+80 ms 可能在心率较快时进入 T 波上升支，因此只能作为备选并记录选择理由。

传统动态心电研究常见“1×1×1”筛查描述，即水平型或下斜型 ST 压低达到 0.10 mV、持续至少 60 秒、与相邻事件有恢复间隔。该规则受导联体系、基线、滤波、心率、体位和设备影响，当前产品只把它保留为未启用的参考配置，不能直接应用于病例。

### 2.2 标准静息 12 导联与急性场景

急性冠脉综合征的标准 12 导联 ECG 在 J 点判读，并要求至少两个解剖相邻导联。2025 ACC/AHA 指南列出的参考包括：

- 水平型或下斜型 ST 压低 ≥0.5 mm，出现在至少两个相邻导联；
- T 波倒置 >1 mm，出现在至少两个相邻且有明显 R 波或 R/S>1 的导联；
- 除 V2–V3 外，J 点 ST 抬高 ≥1 mm，出现在至少两个相邻导联；
- V2–V3 的 ST 抬高阈值按年龄和性别区分：男性 ≥40 岁 2.0 mm、男性 <40 岁 2.5 mm、女性 1.5 mm。

这些阈值属于疑似 ACS 的临床路径，不能直接套用到改良导联 Holter，也不能脱离症状、动态变化、标准 12 导联复查和心肌肌钙蛋白形成诊断。

## 3. T 波描述

T 波优先使用形态学描述，如“倒置、双相、低平、高尖、对称或非特异性改变”。孤立或轻微 T 波变化受年龄、性别、导联、QRS 轴、体位和基线影响，不应由软件自动归因为缺血。

## 4. 必须检查的混杂因素

形成复核意见前至少核对：

- 运动、呼吸、翻身、体位变化和电极松脱；
- 基线漂移、肌电噪声、突然的 ST 跳变和 R 波幅度突变；
- 心率明显变化、房颤、频发早搏或模板不稳定；
- 左束支阻滞、起搏、预激、左室肥厚、早复极、Brugada、心包炎或药物导致的继发性复极改变；
- 导联是否为标准 12 导联、Mason–Likar 或其他改良躯干导联；
- 滤波器低频截止、相位响应和增益是否达到诊断性 ST 测量要求。

若上述信息缺失或波形质量不足，应使用“无法判读”或“伪差/体位改变”，而不是给出阴性结论。

## 5. 软件交互与安全映射

| 医学风险 | 当前交互控制 |
|---|---|
| 未校准幅值被误认为 mV | 页面只显示“设备原始单位”，API 禁止病例 ST 幅度输出 |
| 自动阈值被误认为诊断 | 自动候选固定禁用，趋势区显示不可用原因 |
| J 点定位错误 | ISO/J 游标必须由医生手工校正；提供 5 ms 微调 |
| ST60/ST80 混用 | 测量点在界面和标注备注中明确记录 |
| 只看单导联 | 最多三导联并列复核，并提供全屏 12 导联入口 |
| 忽略伪差 | 非“无法判读”描述保存前要求确认信号质量核对 |
| 源报告与软件结果混淆 | 源报告线索独立标注来源，不生成软件解释 |
| 急症场景延误 | 判读边界弹窗明确提示急性症状应立即进入临床急症评估 |

## 6. 后续开放自动候选的最低条件

1. 冻结并验证导联体系、电极位置、采样率、增益、单位和时钟。
2. 验证诊断性 ST 分析滤波器的低频截止、幅频响应、相位响应和基线稳定性。
3. 建立经专家标注的 QRS 起止、J 点、ISO、ST60/ST80、T 波形态和伪差金标准。
4. 冻结候选事件阈值、持续时间、事件合并和排除规则，并对每个版本进行独立验证。
5. 分导联、体位、心率、传导异常、起搏、性别、年龄、设备和机构报告敏感度、阳性预测值、假报警率及置信区间。
6. 在可用性测试中验证医生能区分候选、源报告线索、人工修正和最终报告结论。

## 7. 主要医学来源

- [2025 ACC/AHA/ACEP/NAEMSP/SCAI 急性冠脉综合征指南](https://www.jacc.org/doi/10.1016/j.jacc.2024.11.009)：疑似 ACS 的相邻导联、J 点 ST 抬高、ST 压低和 T 波倒置参考标准，以及常见混杂情况。
- [第四版心肌梗死通用定义（ESC/ACC/AHA/WHF，2018）](https://www.jacc.org/doi/10.1016/j.jacc.2018.08.1038)：J 点、基线和 MI 诊断必须结合心肌损伤证据。
- [2017 ISHNE‑HRS 动态心电与外部监测专家共识](https://www.heartrhythmjournal.com/article/S1547-5271%2817%2930415-0/fulltext)：AECG 的适用范围、导联配置、缺血负荷和信号质量边界。
- [AHA 住院连续 ECG 监护实践标准更新（2017）](https://www.ahajournals.org/doi/10.1161/CIR.0000000000000527)：连续 ST 监测需要标准 12 导联核实，不能单独诊断心肌梗死。
- [AHA/ACCF/HRS ECG 标准化建议 Part IV（2009）](https://www.jacc.org/doi/10.1016/j.jacc.2008.12.014)：ST、T、U 波标准术语和 T 波描述原则。
- [ACC/AHA 动态心电图指南（1999）](https://doi.org/10.1016/S0735-1097(99)00354-X)：PR 基线、J/J+60–80 ms 与传统动态 ST 事件筛查描述。

以上资料用于约束研究界面的术语和安全设计，不构成对当前算法临床有效性的证明。
