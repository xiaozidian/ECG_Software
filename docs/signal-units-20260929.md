# 波形单位、导入假设与纸面增益验证

日期：2026-09-29。范围为信号元数据和显示／导出标度，不改变原始采样、RR、心搏类型或诊断算法。当前 DATA 输入尚没有经设备资料核验的电压校准，不把设备数值标成真实 µV。

## 可观察结果

- 原始、连续、事件、批量小图条与报告波形统一返回 `units=device_unit`、`calibration_verified=false` 和设备单位说明；密度图同步。静态演示保留“已上传源 DATA 片段”来源说明，并使用相同单位契约。
- `signal_profile` 明确当前导入假设：200 Hz、8 通道 little-endian int16，存储 I／II／V1–V6，推导 III／aVR／aVL／aVF。`device_verified=false`；这不是设备格式已核验的声明。新模块纳入后端计算依据指纹。
- 连续波形的显示控制由容易误解为电压标定的增益改成 0.5×／1×／2×；标尺注明 `1000 u`，u 为设备单位。原始数值、导联运算和显示缩放行为保留。
- 当前未校准报告继续采用逐导联自适应幅度，旧增益设置禁用且说明“不应用”，不显示虚假的 mm/mV。波形自身的实际纸速仍独立标注。
- SVG／PDF 只有在 `calibration_verified` 严格为 true 且单位为 uV／µV／μV／mV 时才使用物理增益；mV 与 uV 的倍率正确换算，1 mV 校准脉冲保持一致。该辅助函数仅做单位转换与保护，不验证校准真实性；当前 DATA 读取器不会输出已验证标志，也不借用研究测量的用户输入系数作为采集校准。
- PDF 字体对 µ 的显示初检出现缺字，输出标签改用等价 ASCII `uV` 后重新渲染确认。

ADC 数值到物理单位通常需要增益、基线及单位等来源信息，参见 [PhysioNet WFDB header 官方说明](https://physionet.org/physiotools/wag/header-5.htm)。本项目没有将 WFDB 的缺省增益套用于专有 DATA 文件。

## 边界与下一步

设备 ADC 增益／基线、实际采样率、通道映射和采集完整性仍需与设备资料和已知校准信号逐项核验；这轮只是明确现有假设、去掉错误物理单位。算法及医生完整工作流的临床验收尚未完成，不宣称全部功能已达到临床就绪。

下一步：为偶发“软件文件已更新”拒绝补充仅记录模块名与文件元数据差异的诊断证据，定位触发源；保留失效保护，不以自动重试或绕过保护掩盖问题。
