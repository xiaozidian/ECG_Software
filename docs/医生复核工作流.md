# 医生复核工作流

## 1. 软件目的

CardioInsight Holter 的核心任务，是让医生在一个连续、可回退、可追溯的病例上下文中完成动态心电人工复核，并形成报告草稿。软件首先服务于“原始波形可信、候选结果可回看、医生修改可追溯、报告内容可核对”的闭环，不把自动候选包装成独立诊断。

## 2. 主流程

| 步骤 | 医生问题 | 主要操作 | 进入下一步前应知道什么 |
|---|---|---|---|
| 1. 波形复核 | 数据能否判读，候选心搏在哪里？ | 选择 1–3 导联、缩放和平移波形、查看坐标、散点圈选、定位异常与伪差 | 原始波形和主要候选位置已经看过 |
| 2. 模板编辑 | N/S/V/X 源分组中是否混入不同形态？ | 切换源类别、形态叠加框选、自建模板、逐搏人工改型 | 哪些是源分组，哪些是医生覆盖，哪些仍待确认 |
| 3. 趋势与 HRV | 全天统计是否受异常 RR 或伪差影响？ | 核对心率趋势、RR 直方图、Poincaré 与 HRV 对照 | 统计口径、数据时长和不可比项已经明确 |
| 4. ST‑T 复核 | 是否存在需要人工描述的动态复极变化？ | 查看原始多导联波形、调整 ISO/J/ST60/ST80、记录信号质量和人工描述 | 当前只完成人工复核，不生成自动缺血诊断 |
| 5. 事件候选 | 哪些候选事件需要接受、排除或进一步回看？ | 按类型筛选、核对阈值、跳回原始波形 | 报告中采用哪些候选、排除哪些伪差 |
| 6. 报告 | 如何把证据、统计和结论组织成可审核文档？ | 选择报告页、核对图条和全导联、编辑结论、保存草稿、审核或导出 | 报告状态与医生审核状态明确分开 |

## 3. 导航规则

- 工作台和患者管理属于病例外入口；选择病例后才出现六步病例工作流。
- 六个步骤始终保持同一病例，不要求医生每页重新选择患者。
- 顶部流程条显示当前步骤、已查看步骤和明确的下一步；任一步都可返回前一步补充复核。
- “已查看”只记录当前浏览器中的导航进度，不代表候选已接受、医学复核已完成或报告已审核。
- 左侧导航和顶部流程条使用相同顺序与命名，避免“编辑”和“波形复核”前后颠倒。

## 4. 模板编辑中的 N/S/V/X 规则

- N、S、V、X 作为源 EBI 类别，必须在页面顶部始终可见，并同时显示英文代码、中文名称和心搏数。
- 未选中心搏时，按 `N` / `S` / `V` / `X` 或 `1`–`4` 切换源类别。
- 选中心搏后，按 `N` / `S` / `V` / `X` / `P` / `O` 写入医生人工类型覆盖；`Backspace` 恢复源类型，`Escape` 清除当前选择。
- 自建模板保留父类别和实际样本索引；它不是自动分类器，也不自动改变下游事件和报告统计。

## 5. 后续优化方向

1. 把事件“接受 / 排除 / 改类”与模板人工覆盖纳入统一的分析版本，并提供撤销、差异和可重放重算。
2. 为每一步定义真正的业务完成条件，例如波形质控确认、模板改动已保存、事件队列无未处理项、报告已审核；在这些条件可验证前，不把导航访问状态称为“完成”。
3. 把趋势、ST‑T、事件和报告中的任意数据点统一链接回同一个原始波形定位器，减少重复页面和重复图表。
4. 增加病例级待办摘要，只显示“下一件需要医生处理的事”，而不是让医生逐页寻找未完成项目。
5. 在多人版本中把复核人、审核人、版本、签名和退回原因纳入权限与审计流程。
