# 报告图条与房颤片段精确往返

## 可观察结果

报告网页编排、导联／区间页及候选波形旁增加“保存草稿并复核片段”。先保存报告的人工文字和选图，再按病例请求版本、分析依据与片段 ID 进入房颤／房扑页，展开对应编辑器。不是跳到第一个事件，也不使用相近时间猜测。

房颤页提供“返回入报图条”，回到原报告子页并聚焦返回提示。浏览／返回不会自动确认片段或审核报告；房颤表单未保存内容仍按已有规则在本窗口暂存，刷新关闭不保证保留。

当片段状态或端点改变，旧选图保留且失效。点击“核对当前片段图条”，读取同一片段的新事件及波形，再显式替换：

- 自动替换保留原顺序、导联和图注，明确重置为自动 7 秒／至少 5 搏，不静默沿用可能不含事件的旧人工区间。
- 也可拖动橘色游标或输入起止后“应用区间”，以当前人工区间替换旧图条，不重复追加。
- 替换前左侧入报勾选框及波形旁普通入报动作禁止绕行，避免丢失图注。原类别确认和相关人工文字确认失效，须重新核对。
- 已失效但仍能精确对应当前片段的已选图条也可进入复核，不先删除医生设置；原片段被删除、排除或不能唯一定位时，不自动切到其他片段。

## 数据契约

Python 与浏览器报告事件增加 `rhythm_episode_id` 元数据：源心搏连续段为 `beat-<start_sample>`，普通源标注为 `source-<id>`，保存后的片段标注 `af:<episode_id>` 还原原 ID。与房颤初始文档的映射逐项比对。此字段不更改诊断、筛查阈值、原始采样或事件专属依据公式。

跳转需要当前报告分析依据；保存失败、未应用的游标、保存期间新编辑、病例／页面变化及依据变化均停止跳转。双击不能触发重复保存。波形读取完成前不允许替换，已存在新事件选图时拒绝制造重复。旧源事件保存为片段标注后的事件 ID 变化通过原 ID 和 `annotation:af:<episode_id>` 两个明确候选读取处理，仍须唯一匹配片段 ID。

## 验证

- 新增 6 项 Python／JS 对照测试：AF、AFL × 源心搏、源标注、已保存文档，检查 ID、边界、状态及原标注不变。
- 1 项 Node 驱动测试运行生产函数：草稿保存、相同片段定位、失效选图保留、正文／图注相关状态、人工区间替换、重复入报保护、并发点击、保存失败、删除／重复 ID、版本与病例变化，以及房颤入口的九类成功／中断情况。
- 本轮相关专项 249 passed（45.54 秒）；静态演示构建 1 passed（0.40 秒）。完整回归结果在项目更新记录中另列，不能由专项推断全量通过。
- 收尾完整回归 12 failed / 1522 passed / 1 warning（211.72 秒）；12项失败为此前记录的三个不可读病例及相关数据断言。首次全量额外13项失败来自旧提取式测试夹具没有提供新增依赖／旧字符串断言，补齐后相关130项通过，最终失败清单回到既有12项，未删测试或放宽产品保护。
- 本地独立 8766 服务仅使用 90 秒纯数学合成波形、四个手工测试片段和临时数据库，未改真实患者报告。实际浏览器跑通图注／正文保存 → 10–20 秒片段定位 → 改为 12–20 秒并确认 → 返回 → 读取当前波形 → 自动替换 → 保存。总图条仍为四条，正文及图注不丢失，报告未自动审核。
- 再从另一个失效的已选图条精确进入 30–40 秒片段，保持十二导联及独立图注，返回后输入 27–36 秒人工区间并应用、保存，显示 9 秒／9 搏及原十二导联。左侧绕行勾选禁用。键盘 Enter 可触发核对当前片段；浏览器无 warning/error。
- 桌面 1280×900 和窄屏 390×844 局部验收；窄屏新按钮 16px、44px，文档宽度等于视口 390px。沿用工作台身份、分组与可见焦点，不做营销式换肤。截图来源见 [验证目录](validation/rhythm-report-return-20260930/README.md)。
- 机械设计扫描仅给出颜色／字号与旧设计文档不一致的 advisory；本次唯一新增字号 16px 是窄屏操作要求，未扩展调色板。旧 sidecar 与产品文档格式漂移未作为本任务副作用修复。

## 边界与下一步

这是一条医生复核路径的工程改进，不是房颤检测性能或临床验收。一次节律修订可能使同类多条图条失效，它们仍需逐一核对，不能批量冒认为已确认。真实设备标定、独立算法性能、完整病例输入与目标医生连续任务仍需验证。下一步核对源片段事件 ID 转换后的跨页复核，以及医生批量核对失效图条的耗时与漏复核风险。
