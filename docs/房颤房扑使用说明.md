# 房颤 / 房扑编辑与分析

从“总览”进入“房颤 / 房扑分析”。工作区由全程 RR、小时内 RR、片段列表和连续三导联组成。片段列表、散点和筛查详情在侧栏内查看，三导联保留在主工作区。

## 设置片段起止

1. 点击“新建房颤”或“新建房扑”。
2. 在全程 RR 或小时内 RR 图定位时段，再在三导联波形核对边界。
3. 普通点击移动查看位置。在需要的起点处使用“设为起点”，在终止处使用“设为终点”；右键菜单与工具栏执行相同操作。
4. 拖动“起 / 止”边界线，或直接修改起止时间，可精细调整。边界、持续时间和选区一起更新。“回起点 / 回终点”用于回看当前编辑的边界。
5. 核对起止后点击“保存候选”。保存后可以“继续添加”，或点击“报告筛选”。

没有明确选区时，新建片段的起止留空。普通浏览、平移、缩放和跨小时定位不会把下一次点击自动当作终点，也不会丢弃已经设置的边界。

起止优先显示来源记录的日期和时钟，与波形时间一致。来源没有时钟时，显示从记录开始计算的相对时间。持续时间单独计算。时间落在原始采样网格；当前 200 Hz 来源每个样本间隔为 0.005 秒。片段包含起点样本，不包含终点样本。

Esc 取消当前设置或拖动动作；“取消修改”恢复本次编辑前的边界。尚未保存的本地修改不等于已保存片段，刷新或关闭浏览器前应完成保存或取消。

## 候选、代表图条与入报

编辑页的“保存候选”只保存整段起止和类型，可连续新增多段。在“报告 → 房颤事件”中，点击候选行或时间只查看，不会确认诊断或加入报告。

报告中同时区分两层范围：

- **整段候选**：这段房颤／房扑的完整起止、持续时间和复核状态。
- **本次图条**：准备进入报告的代表波形起止、实际秒数和可用心搏数。

可以浏览候选的起点、中部、末尾或前后波形。在需要的位置选择“选作图条”，再拖动边界精细调整。默认图条时长为7秒，至少5个可用心搏；不足时沿用自动延长规则。显示8搏是该窗口的实际数量，并非固定要求。图条可以位于长片段中部，不会因此改写整段候选的起止。

“选作图条”形成待应用范围。明确点击“确认整段并入报”后，核对整段范围和本次图条范围，再一次提交；不必先应用区间再重复确认。取消确认会保留所选范围。若只需要先保存待确认草稿，可勾选入报或使用原有应用区间操作；这两个入口采用一致的待确认规则。最终审核仍只检查本次实际使用的片段，未使用候选不增加逐条确认关卡。

确认整段会记录该段房颤／房扑判断；入报保存的仍是选定代表图条。已确认片段按既有口径参与确认时长和负荷统计。改变整段起止或类型后需重新复核，单独调整代表图条不会改写整段边界。

取消入报勾选会移出对应图条。需要改变整段起止时，从报告选择“修改起终点”，完成后返回原图条重新核对。删除或排除片段时，应核对相关已选图条和手写结论。

## 散点与 RR 筛查详情

相邻 RR 散点帮助定位不规则时段，原始连续波形用于核对形态和边界。RR 不规则提示不能代替医生诊断，筛查器未分析 P 波，不能据此自动判定房扑，也不能排除早搏或伪差。

“检查全程覆盖 / 检查选区覆盖”是只读检查。它显示可评估、提示候选和未评估窗口，不直接保存诊断片段。未评估、未提示或没有已保存片段，都不代表该时段正常。

重分析使用固定 30 秒窗口，保留当前工程筛查条件：至少 20 搏、正常类型占比不低于 90%、有效时间覆盖至少 25 秒，以及既有 RR 不规则性规则。这些数值是当前实现的筛查规则，不是诊断标准。重分析只处理相应可评估范围内的算法待复核片段，保留人工片段、源片段、医生已确认 / 已排除的结果和未评估区域。

确认负荷以完整记录时长为分母，重叠时段按既有规则合并统计，只有已确认片段参与确认负荷。待复核与确认的 AF / AFL 区间按现有规则排除在窦性专用 NN 分析之外；这里的编辑不改写 NN 定义。

## 未保存修改

切换候选、报告类别、筛选条件、页面或病例前，系统先在当前位置提示。选择“继续编辑”会保留当前输入；选择保存／应用后继续，会先完成原条目的保存；选择放弃只丢弃尚未应用的修改，保留已保存内容。图条编辑和综述模板在关闭时采用相同方式。

报告结论及已应用设置自动保存；尚未应用的游标或研究测量输入不会阻止这些内容保存。若报告草稿保存失败，离开前可重试、继续编辑或明确放弃，避免进入其他页面后再被旧修改阻挡。

## 保存和修订

保存成功后，列表和状态会更新。若显示“保存结果待核实”，点击“核对保存结果”。系统会比对最近一次保存的操作回执和片段内容：已保存时直接恢复成功状态，不重复插入；尚未写入时提示重新核对后保存；记录已经变化时重新载入当前内容。版本冲突、病例变化或源依据变化时，应重新载入当前内容再编辑。

撤销和重做作用于节律片段修订历史。撤销恢复片段，并不自动替医生重新选择报告图条。原始心电来源保持只读，人工修订与审计记录单独保存。

三导联可以切换为 12 导联核对，返回后继续当前片段编辑。设备单位和显示增益沿用波形设置；电压未校准时，屏幕显示大小不能当作 mm/mV 标定。
