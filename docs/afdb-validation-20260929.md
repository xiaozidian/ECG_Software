# 房颤 RR 候选的 AFDB 基线对照

日期：2026-09-29。结论：**已建立并运行独立公开人工节律标注对照；当前 RR 规则存在显著误提示及个别严重漏提示，不足以证明医生可直接依赖其自动诊断。** 本轮没有根据结果修改算法门槛，也没有把软件测试通过作为临床性能通过。

## 数据、方法与可重现性

在结果运行前写定[协议](afdb-validation-protocol.md)。数据来自 [PhysioNet MIT-BIH AFDB 1.0.0](https://physionet.org/content/afdb/1.0.0/)，ODC-By 1.0，原始方法引用见协议。下载 79 个公开标注／头文件／目录说明文件，加官方 SHA-256 清单；全部摘要核验。没有下载波形或读取、上传本项目患者数据。

主集合为 23 条有明确头文件时长的记录，合计 843,406.880 秒（约 234.28 小时）。00735、03665 的头文件时长为零，按预定规则不猜测完整时长，列为排除。人工 `.atr` 作参考节律；自动 `.qrs` 提供 R 峰位置，未把它称为人工 QRS 真值。05091、07859 的人工修正 `.qrsc` 另列，与同记录自动版本成对比较，不额外计入 23 条记录。

`.qrs/.qrsc` 均不区分心搏类型，适配器输入 N 仅表示未分类的 RR 序列，并不能证明正常搏。250 Hz 标记映射为软件所用的 200 Hz 时标，最大位置误差 2 ms；参考节律保持原始时间。应用实际 `screenAFResult` 在 Node 中运行，不复制检测器到评价脚本。不读取波形意味着本轮不能验证 P 波、QRS 分类或波形噪声排除；数据集已知缺失块和自动检测错误仍可能影响结果。

逐窗半开区间与人工节律精确求交，混合窗不删掉。首个明确标注之前合计 7.900 秒未知，未当作正常。主集合 28,126 个窗口，27,353 个已评估、773 个因规则或尾窗被跳过；时间覆盖与窗口数量覆盖不同。

## 主结果（23 条自动 R 峰输入）

以下均按**时间**加权，不是事件级或患者级指标。条件指标只覆盖已评估且有参考的区域，必须和未评估时间一起理解。

| 指标 | 结果 |
| --- | ---: |
| 已知参考总时长 | 843,398.980 s |
| 总体已评估时间覆盖 | 97.29% |
| 参考 AF 可评估时间覆盖 | 97.73% |
| 已评估区域条件灵敏度 | 92.53% |
| 已评估区域条件特异度 | 87.18% |
| 候选时间阳性预测值 | 82.81% |
| 全参考 AF 时间被候选覆盖 | 90.43% |
| 参考 AF 负荷／候选负荷 | 39.87% / 43.53% |
| 候选负荷相对参考误差 | +3.66 个百分点 |

时间混淆量：TP 304,044.748 s，FN 24,558.488 s，FP 63,093.300 s，TN 428,885.564 s；另有未评估 AF 7,628.780 s、未评估非 AF 15,188.100 s。未评估没有计为阴性。

记录级条件灵敏度均值 93.97%（23 条），条件特异度均值 86.04%（21 条有非 AF 分母），阳性预测值均值仅 63.82%（23 条）。不能仅展示时间汇总 82.81% 而隐去低 AF 负荷记录中的大量误提示。

人工 AFL 参考时间中有 606.792 s 被提示为 AF 样候选，J 中有 212.532 s，其他节律 N 中有 62,273.976 s；算法不识别 P 波或房扑机制，因此仍必须人工鉴别。

## 关键失败与成对核验

- **07859：** 全部已知参考均为 AF。自动 `.qrs` 下条件灵敏度 54.68%，全 AF 候选覆盖 53.28%；人工修正 `.qrsc` 后条件灵敏度 46.33%，全 AF 候选覆盖 **46.28%**，尽管 AF 可评估覆盖达 99.88%。更可靠的 R 峰并没有消除该规则的漏提示。
- 07859 的 `.qrsc` 有 1,226 个已评估窗，658 个未成为候选；其中 655 个未满足 CV≥0.12（509 个仅 CV 不满足，144 个 CV 与 RMSSD 均不满足，2 个三项均不满足），另 3 个仅转折率不满足。这是固定规则的失败定位，不是降低阈值就一定安全的证据。
- **04015 / 05091：** 主集合中时间阳性预测值分别仅 5.23% / 4.26%，说明低 AF 负荷病例的候选复核负担可能很高。
- **08219：** 条件特异度 55.88%，参考负荷 21.59%，候选负荷 54.83%，不能把候选时长直接作为确诊负荷。
- 两条有人工修正 R 峰的记录合计：自动输入的条件灵敏度／特异度为 54.77% / 95.02%，人工修正输入为 46.44% / 96.54%；不能用这两条特殊记录估计整个数据库的人工修正表现。

所有记录都已查看，本库今后只能作为已知基准或明确开发集，不再称为未见盲测集。此次没有按失败病例调参或隐藏不利记录。

## 评价器自身验证

- 新增 21 项测试覆盖时间映射、非法输入、未知参考、分母为零、混合窗、弃权时间、记录级均值和应用实际筛查调用。
- 独立审计器 `scripts/audit_afdb_scoring.py` 不调用原求交函数，而是在原始 250 Hz 采样网格建立参考与输出向量并计数。25 次记录运行 × 7 类时间，共 175 项比较，零超容差差异，最大浮点差 1.18×10⁻¹¹ 秒。
- 核心房颤及评价器专项 79 项通过；随后补充原始网格审计的 3 项测试，评价器专项最终 21 项通过。完整回归在前 18 项加入后为 940 passed（177.81 秒，1 条既有重复 ZIP 测试警告）；最后 3 项按专项验证，未冒称为新的完整回归计数。
- 算法、协议与评价脚本的 SHA-256 在运行前后核对一致；结果保存输入摘要、运行时版本和源文件快照，输出目录拒绝覆盖。临时目录查找使用的未匹配 shell 通配符曾返回错误，随后使用实际目录完成读取，不影响数据或结果。
- 第二次离线运行的 `records.json` 和 `windows.csv` 与基线逐字一致。正式结果及算法快照摘要复核一致；验证环境 Python 3.12.14、WFDB 4.3.1、NumPy 2.5.3、Node v26.0.0，未改动应用依赖或患者库。
