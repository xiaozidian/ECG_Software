# 高级研究测量：实现范围、方法和验证边界

本实现不构成医疗器械临床验证。原始 DATA 只读，以当前人工修订心搏为定位依据；所有结果均为研究测量或工程筛查，不自动写入诊断结论。无有效数据输出“条件不足”，不输出正常值或虚假的零值。

## 数据与性能

- 原始格式：200 Hz、8 通道、int16 little-endian。输入通道按现有导入器标为 I、II、V1–V6；不使用显示滤波或显示降采样结果。
- QT / VCG / TWA 分析使用者指定的 30–600 秒片段（默认前 300 秒），**不是全程 TWA 最大值**。SAP 研究筛查使用单独的可指定范围，默认全程；不假定该范围等同睡眠。HRT/DC 沿用全程计算。
- NumPy 只读 memmap 按心搏窗口读取；没有把全程波形转成 JSON。8 项有界内存缓存以原文件签名（设备号/inode/大小/mtime/ctime）、算法版本、当前心搏类型/RR、AF 区段、窗口和设置为键；返回深拷贝，避免调用方污染缓存。报告另外绑定后端构建及原文件内容摘要，见 [计算依据说明](analysis-provenance.md)。
- 默认设备单位，不将显示 gain 当采集电压系数。可显式录入统一 µV/设备单位及校准依据；仅表示按用户提供系数换算，不能替代采集链校准验证。不同通道增益不能使用统一系数，应先补充正确导入映射。
- 当前临床索引仍会在请求中重建；重复请求缓存节省的是原始信号计算，不承诺整个 API 零延迟。

## QT / QTd

正常 N-N 与采样间距一致（误差不超过 10 ms），排除 AF 区段及相邻异常搏；所选心搏的前后 RR 均至少 700 ms、相邻 RR 变化不超过 20%。这是当前固定中位心搏窗口的保守质量限制，高心率不能通过时需换窗，不能报正常。

最多前 64 个符合条件心搏，R 前 250 ms 至 R 后 650 ms，PR 区段去基线，中位形态误差剔除后至少 8 搏。每导联三点平滑，QRS 幅度/噪声阈值寻找起点，T 末支最大下降斜率与 PR 基线交点寻找终点；保留异向末支。同向显著波瓣间持续回基线时提示 T/U 或后续波歧义，交由人工端点，不自动截断。低幅、未回基线、窗口边缘、削顶、平线及不合理端点输出失败理由。这些工程门槛不是通用 T/U 波分类器。

逐导联输出 QT、QTcB=QT/√RR、QTcF=QT/RR^(1/3)（RR 用秒）。至少 6 个有效采集导联、其中至少 3 个胸导联才输出 max(QT)-min(QT)；门槛为软件工程质控，非通用诊断标准。四个代数派生肢体导联不作为额外独立测量纳入统计。200 Hz 时间分辨率为 5 ms，不代表准确度为 5 ms。

支持逐导联人工 Q/T 数值端点、排除与恢复自动。人工值按 5 ms 量化；心搏修订、原文件或片段变化会使端点依据失效并阻止沿用。平线/削顶不能靠手工端点绕过。算法是本项目的可复核工程实现，**不是 ECGPUWAVE 的复现，也未完成 QT 数据库临床误差验证**。

方法参考：[PhysioNet ECGPUWAVE 的 QRS / T 波定位资料](https://physionet.org/content/ecgpuwave/1.3.4/)。2026-09-29 已完成 QTDB 单搏端点工程对照：25 条开发、80 条评估；评估组自动覆盖 57.05%，成功输出 QT MAE 47.455 ms，仍不足以独立作临床测量。新版主要增加歧义拒绝与异常保护，共同成功样本的端点并未改善。完整输入条件、失败候选、逐搏结果与限制见 [QTDB 验证记录](qtdb-validation-20260929.md)；该两导联组件检查不等同于八导联 QTd 或目标设备临床验证。

## 推导 VCG

只有使用者明确确认标准电极位置、通道顺序 I/II/V1–V6 和相同增益，且 8 通道均有效，才计算 Kors 回归 XYZ。改良胸导联 Holter 不能直接套用。三个投影使用相同横纵尺度并保留负轴；展示中位心搏轨迹及峰值模长，不输出疾病/空间角风险判定。无电压校准时为设备单位。

系数顺序 I、II、V1、V2、V3、V4、V5、V6：

```
X = [ .38, -.07, -.13,  .05, -.01,  .14,  .06, .54 ]
Y = [-.07,  .93,  .06, -.02, -.05,  .06, -.17, .13 ]
Z = [ .11, -.23, -.43, -.06, -.14, -.20, -.11, .31 ]
```

来源：[Tereshchenko 实验室 Kors 变换](https://github.com/Tereshchenkolab/Global-Electrical-Heterogeneity/blob/master/Kors_git.m)。这里只使用公开变换系数，以矩阵乘法独立实现；未复制其程序或引入依赖。

## TWA 频谱研究测量

128 连续正常搏、步长 64 搏，不跨异常搏补点，不进行奇偶替换。RR 400–1500 ms、相邻变化 ≤20%；前后边界、削顶、QRS 相关 ≥0.9、ST-T 形态相关 ≥0.6 作为工程质量门槛。QRS 相关判别不等于完成了运动/呼吸伪差排除。

原始 R 对齐、PR 去基线。共同 ST-T 窗为 R 后 100 ms 到 min(450 ms, 窗内最短 RR×0.6)，这是固定共同窗研究测量，**不是逐搏 T 端点的临床 TWA 检查协议**。逐时点沿心搏轴做 128 点 FFT，功率=|FFT/128|²，再在 ST-T 时间轴取平均。

频谱幅度 A=√max(0,P(0.5)-mean(Pnoise))；噪声带 0.431–0.460 cycles/beat。K=(P(0.5)-mean(Pnoise))/std(Pnoise)，噪声方差不足返回空值，不输出无穷大。已知 ±A 合成信号可恢复 A（区别于峰峰值 2A）。展示所有合格窗口/导联组合与最大幅度组合的奇偶均值和频谱；不进行多重比较校正，因此不作阳性/阴性结论。

文献方法依据：[128 搏频谱与噪声带公式研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3288719/)、[开放 TWA 基准实现论文](https://physionet.org/files/challenge-2008/1.0.0/papers/0509.pdf)。本实现不声称达到这些论文的性能；未验证微伏级噪声、不同仪器滤波响应或真实 TWA 检出率。

## ECG 周期性 RR 变化筛查（SAP 页）

5 分钟不重叠窗，正常 NN ≥95%、至少 100 个间期、有效点最大缺口 ≤3 s。1 Hz 插值、线性去趋势、5 s 平滑；25–130 秒周期范围内归一化自相关、Hann 功率谱频带占比及 RR P95-P5。

自相关 ≥0.5、频带占比 ≥0.6、RR 振幅 ≥80 ms 时标记**周期性变化候选窗口**。这是一种透明的、未经临床验证的工程筛查指标，不是 ACAT 算法复现；没有输出睡眠呼吸暂停事件次数、AHI、患病概率或睡眠分期。未达到阈值不能排除呼吸暂停。心律不齐、周期性肢体运动等也可能导致类似变化。

研究背景：[Hayano 等 ECG CVHR 筛查原始研究](https://pubmed.ncbi.nlm.nih.gov/21075771/)。临床确诊仍需适用的 PSG/HSAT：[AASM 诊断指南](https://www.aasm.org/resources/clinicalguidelines/diagnostic-testing-osa.pdf)。本工程阈值没有继承文献 ACAT 的敏感度/特异度。

## HRT / DC 与 VLP

HRT/DC 继续使用 `report_sections.py` 中已有的连续正常 RR 质量门槛、PRSA 及 TO/TS 定义，合格样本不足不报告值。单独打印与主报告均可选，网页现可查看对应恢复曲线/PRSA。具体公式见 `report-analysis-methods.md`；不输出风险等级。

VLP 保留不可用：200 Hz 的 Nyquist 频率为 100 Hz，不能覆盖常用 40–250 Hz 晚电位分析；插值不能创造未采集信息。需要高采样率、足够采集带宽、电压校准和低噪声信号平均。参考：[信号平均 ECG 的原始研究采集与处理参数](https://pmc.ncbi.nlm.nih.gov/articles/PMC10456944/)。没有生成伪 RMS40 / LAS40 / fQRS 数值。

## 界面、导出与限制

本地“报告 → 报告 → 研究指标测量与复核”提供按需计算、片段参数、校准依据、逐导联 QT 修正、候选回看及独立打印/PDF。主报告可勾选四类新增研究页。使用当前算法与保存设置生成网页/PDF 共用的证据文档；人工端点携带依据版本，发生变化后必须重新复核。参数更改后隐藏旧结果，未计算参数不会假装已生效。

纯静态 GitHub Pages Demo 没有 Python 原始采样计算服务，明确禁用这四项；不会塞入预制数字。HRT/DC 的既有浏览器计算仍保留。原始数据和既有临床注释不改写。

测试覆盖已知 QT/TWA/Kors 合成信号、空/平线/AF/缺口、非法参数、单位缩放、端点失效、缓存隔离、API 及网页/PDF 证据一致性；**功能测试通过不等于临床性能验证**。公开 QTDB 组件误差已记录，其余算法仍需各自的独立对照集；还需目标设备校准文件及真实伪差、跨导联和人工纠错验证。
