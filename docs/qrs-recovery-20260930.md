# 波形／QRS 输入恢复实验：实现与执行状态

## 要解决的问题

既有 LTAFDB 开发评价中，112 自动 QRS 输入整段未评估；05 的短 AF 事件在若干熵聚合方案中漏提示。只修改房颤阈值不能证明改善了输入漏搏。本实验固定使用完整记录 00、05、112，各自两条导联独立重检 QRS，再将同一 RR 筛查用于原始自动标注和新检测位置，分开评价 QRS 与 AF。

这是已知失败记录的开发实验，不是独立临床验证。协议见 [固定协议](qrs-recovery-protocol-20260930.md)。三条完整记录、69.283 小时、九组比较现已完成：112 的输入缺失明显恢复，但既有房颤基线仍有较大漏提示和误提示；不同导联的定位表现差异明显。**不替换生产算法，不宣称临床可用。**

## 已实现

- `scripts/audit_qrs_recovery.py`：官方文件 SHA-256 校验，独立环境 WFDB 4.3.1 XQRS 默认配置，两导联分别检测、30 分钟核心区加前后 10 秒上下文、只保留核心内位置。
- 检测不读取参考标注，不用参考挑导联、补搏或调整阈值。非有限输入块保留为缺口，禁止插值后冒充有效信号；未分类检测仅以明确标注的 N 代理进入研究用 RR 比较，不能当正常搏真值。
- 原生采样上一对一最大数量匹配，保留 ±6／12／19 样本三种容差，逐记录／逐核心范围 TP、FP、FN、Se、PPV；后续保留 AF 未评估、误提示、短事件捕获及原生网格时间守恒审计。
- 检测前保存 `inputs.json` 和经过字节核验的源码快照，读取参考前保存每条记录的检测结果；最终输入、源代码和快照都复核成功才写 `summary.json`。评分失败不抹掉检测证据，拒绝覆盖既有输出目录。
- 拒绝非有限、布尔、非整数、逆序／重复或越界波峰位置及无效记录长度，不静默修复输入。

### 结论与不利证据

1. **112 存在可恢复的输入缺失，但恢复后仍不能直接诊断。** 两导联已知节律时间的可评估覆盖分别 99.860%／94.717%，然而仍漏掉相当部分 AF，并各误提示约 3.5 小时非 AF。867 个短于 30 秒的 AF 事件，至少半段捕获分别 786／755，完整捕获 734／697；不将触及事件的一小部分算完整检出。
2. **05 的短事件问题不能归咎于原 QRS 输入。** 三个 13.273、5.016、21.641 秒参考 AF 在本轮相同 RR 基线下，三种输入均全部捕获；换新检测反而增加非 AF 误提示。这与此前熵聚合漏掉短事件的结果并存，说明仍需针对聚合／局部定位修正，而不是替换输入就宣称解决。
3. **00 显示导联和定位的代价。** 导联 1 的匹配 Se 随容差从 ±6、±12 到 ±19 样本变化为 70.078%、91.762%、96.883%，提示不能把所有未匹配都解释成完全漏检；应结合波形检查定位误差。导联 2 虽 QRS Se 很高，仍有 75.227 分钟参考 AF 被质量规则拒绝评估，157 个窗标为 low_quality。当前规则含 RR 300–2000 ms、有效比例与覆盖要求，但本轮没有证明每个拒绝窗的具体生理／噪声原因，不能据此直接放宽门槛。
4. 两条导联在不同记录上优劣互换，**不按参考结果挑选“最好导联”上线**。下一步固定波峰定位校正及双导联一致性／波形质量评价方案，分开处理定位误差、真实短 RR 与伪差；再检查分类和 AF 短事件／误提示代价。仍需独立评估数据、真实设备标定与目标医生完整任务验收。

## 复现

首次结果目录不覆盖；复现时使用新的输出目录，并保持依赖版本一致：

```sh
/private/tmp/ecg-qtdb-validation.uOfnjB/venv/bin/python scripts/audit_qrs_recovery.py \
  --data /private/tmp/ecg-ltafdb-validation.v4BhaB/data \
  --output /private/tmp/ecg-qrs-recovery-replay-new
```

独立复算使用 `scripts/verify_qrs_results.py --self-test --data <原始目录> --results <结果目录> --output <新的核验JSON>`。它核验计数、输入位置及哈希，不构成对病种真值的独立审核。

## 数据与方法来源

公开 LTAFDB 的自动 `.qrs` 与人工核查 `.atr` 含义不同，不能互当独立检测输入。[PhysioNet LTAFDB 1.0.0](https://physionet.org/content/ltafdb/1.0.0/)；按该数据集要求引用 Petrutiu、Sahakian、Swiryn（2007），并致谢 MEDICALgorithmics 参考标注团队。数据遵循 ODC-By 1.0。

独立检测采用 [WFDB 4.3.1 XQRS 文档](https://wfdb.readthedocs.io/en/latest/processing.html) 所述接口；分块方式、三种匹配容差和记录选择是本项目预先固定的工程实验条件，不是临床标准。
