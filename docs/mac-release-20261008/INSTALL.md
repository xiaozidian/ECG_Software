# Mac 独立功能评估包

仅适用于 Apple Silicon，当前依赖要求 macOS 14 或更高。软件包不含病例和医生工作库。

先运行“初始化Mac评估版.command”，明确指定只读病例来源与独立工作目录；再运行“启动Mac评估版.command”。“检查Mac评估版.command”核对服务和版本；“停止Mac评估版.command”按提示处理未保存工作后停止。旧工作目录必须保留，不能用新目录覆盖。恢复工作使用“恢复Mac评估工作.command”及明确选定的备份。

监听仅本机回环地址，不设置系统服务或开机自启。包为临时签名的工程评估版，没有 Developer ID 公证，也没有另一台 Mac 的实机验证；遇系统拦截应按系统提示处理，不清除隔离属性或降低安全策略。

请由医生核对原始证据。软件和合成测试不能证明临床有效性。
