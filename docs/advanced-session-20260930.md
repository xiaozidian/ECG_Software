# 研究测量暂存与异步结果保护

## 已复现的问题

报告类型／复核状态筛选递归重建网页编排，研究测量也重新挂载。真实浏览器中，尚未计算的起点 12 秒、时长 45 秒在切换“依据失效”后变回 0／300 秒，面板折叠。原计算请求如果在节点脱离时结束，原实现又不会解除该节点的忙碌状态。

## 实现

- `advanced-analysis.js` 的保留挂载只缓存一个面板，以病例、病例打开序号、分析依据及已计算设置为身份。同一上下文的筛选、打印模式、报告子页与保存重绘移动原节点，保留输入、展开状态、结果页签及人工端点。设置的字段顺序变化不造成无谓重置。
- 换病例、重新打开病例、分析依据变化或显式载入不同测量设置，不套用旧面板。计算提交和返回均检查当前身份；迟到结果不能更新新病例或新面板。节点脱离后仍解除原请求忙碌状态，返回可重试。
- 参数修改和 QT 端点修改明确显示“尚未应用”。新增“放弃未计算修改”恢复当前已计算参数／端点；没有计算时恢复初始设置。端点未应用时不能通过切换导联或结果页签静默丢失。
- 未应用修改／正在计算阻止保存、审核、预览、主报告导出及重新载入；PDF 异步读取后再次检查。独立研究打印在读取依据后和等待字体后也检查。保存请求发出后才发生的新输入保留，并提示保存的只是提交时版本。
- 切换病例前提示处理未应用测量；关闭／刷新使用浏览器原生离开提示。暂存只在当前窗口，不是持久化草稿，也不保证刷新后恢复。原始文件、诊断类型、算法阈值和设备校准状态不变。
- 继续使用既有工作台视觉。窄屏输入／按钮 16px、至少 44px，三个计算操作单列；状态不只依赖颜色。

## 验证

- Node 执行实际挂载函数：7 组生命周期（放弃、成功、失败、脱离、依据变化、替换、清除），5 个保存／输出入口拦截，以及 QT 端点页签／导联保护。保留键序变化与显式不同设置分别断言。
- 输出竞态：27 组 PDF 场景，覆盖服务器版本检查、响应和 Blob 等待期间出现未应用测量；预览与重新载入的迟到读取另有断言。原游标／病例／报告版本竞态测试保留。
- 最终相关专项 **82 passed（13.34 秒）**，包括研究算法、报告工作区、导航、单位换算、静态演示构建。完整回归 **12 failed / 1540 passed / 1 warning（216.36 秒）**；12 项仍为已知 3 个未完整下载输入及相关夹具断言，未放宽或跳过。完整回归之后的提示措辞、按钮单列和端点测试补充由最终专项及浏览器确认覆盖。
- 仅在隔离数学合成病例验证：12／45 秒参数跨筛选及数据表格往返保留；未计算保存被拒绝；TWA 页签与结果跨保存保留；QT II 导联 T 终点改为 350 ms，筛选后保留，导联／页签切换被拒绝，应用后保存成功。未修改真实患者报告。
- 1280×900、390×844 检查无新增整页横向溢出。窄屏第一轮三个按钮文字换行较多，集中修正为单列；确认每个按钮 284×44px。状态颜色和焦点沿用原样式。浏览器记录一条故意触发保存门禁的错误日志，无额外异常。
- 手动设计检测 0 反模式、7 条既有颜色及窄屏字号文档建议；未改全局视觉令牌或顺带修复设计文档格式漂移。演示资源、缓存摘要与源码同步，语法／diff 空白检查通过。
