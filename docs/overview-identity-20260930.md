# 总览、房颤片段与波形依据一致性

日期：2026-09-30。工程数据一致性修复；未改变房颤分类器、临床阈值或电压假设。

## 修复内容

- 总览逐搏索引和房颤片段读取加入来源/算法依据 `analysis_basis` 与全局复核修订 `analysis_revision`。读取中途发生修改、客户端携带旧依据时返回冲突。
- 网页以同一依据批量读取两者，再核对逐搏修订和连续波形。重新加载、读取失败时清除旧图形及统计，提供明确重试入口。病例切换和重开同一病例的迟到响应不覆盖新页面。
- 片段保存同时携带全局依据、逐搏修订、片段修订；SQLite 写事务中再次核对全局复核修订，拒绝并发旧内容，保持撤销/重做历史。
- 保存成功后重新读取一致依据。如果保存已完成但刷新失败，明确提示“已保存”，不诱导重复提交。已有片段编辑草稿保留在页面内；旧依据草稿不能直接提交。
- 总览连续波形请求绑定当前依据，失败后撤销旧总览证据。静态演示同步读取标识与保存冲突检查；演示标识仅为本地修订，不等于真实源文件校验。

- 正式患者数据库、源文件和用户 8765 页面未修改或刷新。代码已在隔离服务验证；正式服务需要重新加载当前代码后才能使用，未远端发布。
