# 复核列表序号与异步焦点验证

日期：2026-09-29。范围是模板编辑的全部出现记录，不修改原始波形、心搏分类算法、报告选择或审核状态。

## 已修复

- 原实现切换集合会重置列表位置，却留下旧跳转值；越界值会被静默截到末条。现在每次重新读取集合先清空并禁用定位输入，成功后重置为 1，最大值来自当前集合。空集合或读取失败时保持禁用，并显示记录状态。
- 输入必须是当前范围内的整数。无效值在原输入框提示 `请输入 1–N 之间的整数序号`，不移动列表。滚动、调整窗口和补页返回均不改写正在输入的草稿。
- Enter 与定位按钮等价。定位后把键盘焦点放到精确的目标卡片；跨懒加载页的方向键也走同一路径。焦点本身不勾选审核目标、不修改分类、不加入报告。
- 分页返回晚于筛选／病例切换时不会把旧焦点带回。用户转到其他输入框或滚动离开目标范围后，晚到页面不抢焦点。旧集合失败也不会弹出当前集合的错误；当前集合失败仍提示重试。
- 600 px 以下仅放大定位操作栏：16 px 输入／按钮文字、44 px 输入与按钮高度；说明 14 px。桌面尺寸和原有白／青绿工作台不变。

- 初次专项 25 通过、1 失败：跨页方向键夹具把第 96 条放在错误滚动行外。根据真实每行 6 列、126 px 行高将夹具定位改为 1890 px，未修改产品几何或放宽断言。
