# MIT-BIH 标注驱动统计核对协议（v1）

## 验证对象与边界

本协议先于本轮公开数据运行固定：完整 48 条记录，不挑选病例，不调自动识别阈值。使用参考标注作为输入，验证修订后事件索引、筛选及报告统计；**不是 QRS 检测、逐搏分类、节律诊断或临床准确率验证**。不下载波形，不导入正式病例库，不修改患者报告。

数据：[MIT-BIH Arrhythmia Database 1.0.0](https://physionet.org/content/mitdb/1.0.0/)，ODC-By 1.0。原始引用：Moody GB, Mark RG, IEEE Eng Med Biol 20(3):45–50 (2001)，[DOI](https://doi.org/10.13026/C2F305)。标注意义按[官方符号说明](https://physionet.org/physiobank/database/html/mitdbdir/intro.htm)；历史计数仅作为额外交叉核查，来源为[整条记录计数表](https://physionet.org/physiobank/database/html/mitdbdir/tables.htm)。历史表与当前标注若不同，逐项报告，不调整数据来匹配旧表。

## 映射与时间

WFDB 代码不能直接当作本软件快捷键：A→S，a→Z，L→BL，R→BR，e→W，j→G，/→P，f→PF，Q→OTHER；N、J、V、F、E 保留。本数据库中通用室上性早搏 S 映射到软件 S，但与原始 A 分别报告，不能将其解释为已证明的房性起源。x→O 是非 QRS 标记；| 与 ! 作为 X 断点而不是有效 R 峰，不将其断点数解释为临床伪差数。其余节律、质量和注释标记保留原始频数，但不混作心搏。未知符号使核对停止。

严格保留软件现行 S/V 类别口径：不把 J、Z、融合、逸搏或束支阻滞自动改成 S/V/N。故本验证不声称覆盖所有室上性早搏定义。节律标注不转换成自动确诊；不在本次验证 HRV。

360 Hz 标注位置用整数最近邻映射到 200 Hz（半值向上），仅转换时间戳，不重采样波形。RR 从映射后的连续有效 R 峰重算，断点后第一搏 RR 不可用。保留映射前后的 >2.5 s、>3 s 长 RR 数用于量化阈值边界差异。小时分桶统一用人工时钟 `2000-01-01 23:45:00`，让每条约半小时记录跨越午夜；不是患者实际采集时间。

## 预先规定的检查

1. 逐记录核对全部原始符号频数和官方历史整条表；校验 48 条记录及所有 `.hea/.atr` 的官方 SHA-256，任何缺失或哈希错误终止，不跳过。
2. 连续 S/V 的每个最大连续段按长度 1/2/3/≥4 分组，使用独立 `itertools.groupby` 参考；所有目标心搏恰好覆盖一次，与逐搏总数一致。
3. 联律只描述 N 与同一 S/V 的重复序列。NS、NNS、NSS、NNNS 的所有循环起点均有效，至少两个完整周期；找到最早满足条件的起点后延伸至第一处不匹配（保留符合周期的尾部），同一模式的片段不重叠。遇其他类型立即断开。使用正则表达式实现独立参考；这不是医学诊断持续时长标准。
4. 事件起点决定所属小时，左闭右开；逐搏总数按每搏位置计小时。比较每种模式的事件起止位置与目标搏、分页、时间柱状筛选、小时表与全程表。联律与连续段是重叠描述，不相加为心搏数。
5. Python 与浏览器对同一输入的完整索引逐字段一致。算法语义变化更新 S/V 依据及总索引版本；旧证据须重新确认，不能静默沿用。

统计核对的通过标准为上述软件口径下零差异。官方历史表差异单列，不算自动诊断错误，也不掩盖。输入与算法、参考脚本、依赖版本的摘要进入结果；结果目录拒绝覆盖。

## 运行

使用已有独立验证环境及 `requirements-validation.txt`，不改变应用依赖：

```sh
python scripts/validate_mitdb_counts.py --fetch --data /path/to/mitdb --output /path/to/results
```

首次只下载 96 个标注/头文件、RECORDS、SHA256SUMS 和公开历史计数表。后续离线核对可以省略 `--fetch`。输出 `summary.json`、`records.json`、算法和脚本快照；退出码 1 表示实现与预定参考不符。原始公开文件留在独立目录，不进入应用数据目录或 Git。
