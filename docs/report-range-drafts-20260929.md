# 入报游标暂存与异步输出保护

## 医生操作流程

拖动橘色边界、用方向键微调或确认起止秒数后，尚未应用的区间暂存于当前窗口。切换候选不会删除它；报告上方显示待处理数量，并提供“返回待应用区间”入口。返回时按事件及依据版本定位，不用其他候选替代。

保存、审核、载入服务器报告、A4 预览、打印和主报告 PDF 导出前，必须先应用或明确放弃这些修改。应用仍重新校验原始依据、时间范围和可用心搏数；网络失败、病例变化或验证期间切换波形时，不能静默消费暂存区间。暂存不是已入报，也不是已保存。

“放弃全部游标修改”采用页面内确认，先显示数量与作用范围，默认焦点位于“取消，保留修改”。取消保留区间；确认仅移除临时范围，不回退已应用或已保存的图条。确认期间若有新范围修改，旧确认失效，需重新核对。

## 异步保护

- PDF 下载在读取服务器版本后、取得 PDF 字节后再次检查待应用区间、病例生命周期、报告版本、复核修订、保存状态及未保存修改。有变化时不触发下载。
- A4 预览在异步证据读取完成后再次核对游标；打印在证据读取后以及样式／字体加载后、真正打开打印前再次检查。
- 载入服务器报告过程中新增游标修改时，保留本窗口状态，不用远程版本覆盖。
- 保存请求发出后新增的游标修改仍保留；反馈明确为“已保存提交时的版本；后续游标修改尚未应用”，不表示新范围已保存。
- 换病例前的离开提示包含待应用区间；页面刷新／关闭使用既有浏览器离开保护。浏览器可能按自己的规则抑制提示，因此不能作为持久化备份。

## 实现与验证

实现：`static/js/report-range-editor.js`、`static/js/clinical-ui.js`、`static/js/clinical-workflow.js`。复用现有报告操作栏样式，未改变工作台视觉身份或 A4 输出样式。

自动化验证：

- `tests/browser_range_drafts.cjs` 执行真实范围模块与界面函数，覆盖返回恢复、失败保留、异步应用中保存阻止、不同依据／病例隔离、多个暂存区间、键盘微调、取消／确认放弃、过期确认以及离开保护。
- `tests/browser_range_output_races.cjs` 执行生产输出函数：24 组 PDF 异步场景（3 个等待阶段 × 7 种变化及无变化成功），另测预览、打印证据、打印字体及远程载入等待期间新增范围。
- 修正原 `browser_waveform_freshness.cjs` 中不可到达的 `range-valid` 分支，使成功应用确实检查远程重验证和选图结果，而不是误入切换病例用例。
- 范围、报告一致性、波形时序、精确导航及病例生命周期专项 80 项通过（28.23 秒）；最终完整回归 **1,045 项通过（184.78 秒）**，1 条既有重复 ZIP 测试警告。两个新增 pytest 入口分别运行完整生命周期及异步场景，不把内部断言数冒称为 pytest 测试数量。
- 静态演示专项 5 项通过（1.37 秒），三个演示脚本与源文件逐字一致。JS 语法和 `git diff --check` 通过；8765 服务提供的临床界面脚本 SHA-256 与当前源文件一致，健康检查 `ok`、10 例可读、0 例不可读。只改前端，无须重启或刷新用户原页面。
- 最初演示专项命令引用了不存在的测试文件，未运行测试；用 `rg --files` 确认实际文件后运行上述两个演示测试文件并通过。临时合成服务及标签页已关闭，数据和截图留存可追溯；未推送远端。

真实浏览器只使用独立 8766 服务的数学合成信号与临时数据库：

1. 首条最快心率候选的起点由 28.830 秒改为 27.830 秒，区间由 7 秒变为 8 秒、11 搏。
2. 切换到第 2 条后仍显示 1 处待应用修改；保存被阻止，返回后起点仍为 27.830 秒。
3. 页面内“取消，保留修改”不丢区间；应用成功后已选图条从 1 条增至 2 条，保存为草稿 v3。
4. 再改起点到 26.830 秒，明确放弃后恢复已保存的 27.830–35.830 秒，草稿版本仍为 v3。
5. 只读 API 核对：新图条保存显式区间，原图条仍在；节律修订仍为 1、仍为 3 条片段。未修改真实患者诊断或报告。
6. 桌面 1366×900、窄屏 390×844 检查无整页横向溢出；窄屏确认按钮高度 44 px、提示区宽 302 px。浏览器日志只有有意触发的“尚未应用”保护错误，没有额外错误。

此前使用原生确认框的验证页曾阻塞自动控制；新放弃流程已改为内联确认，当前验证页完整通过，旧临时页已不在浏览器列表。首次专项失败来自测试桩未加载新增范围依赖，补齐依赖后通过，未放宽断言。

## 边界与下一步

暂存仅在当前页面内存中，不跨刷新、关闭、崩溃恢复；依据变化时拒绝复用旧范围，需明确放弃后重新选择。输入框尚未确认的空值／非法字符串不属于有效区间草稿。没有改变心搏识别或临床诊断算法。

本轮证明的是工程流程保护，不是临床有效性或医生可直接使用的全面验收。下一步需要验证长时间多事件核查任务的操作成本，并继续处理临床性能、真实设备标定与医生任务验收。
