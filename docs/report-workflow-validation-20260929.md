# 报告工作流浏览器验收 · 2026-09-29

## 范围与隔离

本轮对既有实现进行实际浏览器复测，并修正一项报告状态显示缺陷。使用 `127.0.0.1:8766` 与独立临时 SQLite 数据库，原始波形只读；报告正文均为明确标注的合成验收文字。没有改写 8765 正式报告、没有执行医生审核通过，也没有刷新用户的正式页面。

本轮不是算法灵敏度、临床有效性、注册合规或完整部署验收。既有算法与报告能力的限制继续适用。

## 发现与修复

**P2 · 报告恢复后状态提示残留。** 初次复测发现载入远端新版本后，正文区已显示“已保存”，审核检查摘要仍显示“有未保存修改”。源于 `renderReportShell()` 更新报告但没有同步 `renderPreflight()`，不是数据丢失。

在报告壳层渲染末尾统一同步审核检查，不改全局样式、医学阈值、导出规则或审核门禁。补充执行实际两段渲染函数的回归测试，先复现失败，再验证以下状态：恢复后已保存、远端依据失效、本地输入保留、保存中、只读、环节未完成与空结论。

修正后重走双窗口冲突与显式恢复，v6 正文、已保存提示和审核检查一致；两个未确认环节仍阻止审核。Impeccable 本轮以状态一致性加固为范围，没有进行视觉重设计。
