# RR 选择与报告交互修复（2026-10-28）

本次在既有源码上定点修复 RR 非空选择、报告缩略卡布局和自动保存。算法计算定义、阈值、采样率、原始波形和平台适配未修改；共同 Python 核心的版本变化来自报告分类确认门槛调整。

## 行为

- 总览 RR / R-R 比值直方图只接受有数据且有来源心搏的档位。点击空档保留原选择；键盘跳过空档。
- 最长 RR 档可直接选择，再逐档选择较短的非空档。少量数据用空心三角提示，真实柱高和计数不变。
- 报告编排缩略卡一行两个，1/3/12 导联外框一致。缩略图直接按卡片全宽绘制，1/3/12 共用相同时间轴与预览增益，完整显示所选导联；明确标示幅值缩略比例，展开十二导联仍单列并保留诊断显示增益。
- 移除可见的保存草稿和分类筛选完成控件，编辑自动保存。保存期间继续输入、离页前写入、重开恢复和版本冲突保护保留。
- 仅保存报告不使临床读取缓存或 RR 来源选区失效；实际标注、模板和诊断修改继续使对应版本失效。
- 移除逐类浏览确认的人工门槛；过期图条、未确认事件/诊断、人工诊断待复核及并发版本检查保留。
- 报告图条的编辑、重命名、打印标记和删除菜单继续由图条自身处理，不批量替换为心搏修改菜单。
