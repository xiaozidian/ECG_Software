# A4 图条输出设置与预览／PDF 一致性

完成日期：2026-09-29。仅验证软件输出；不代表真实电压校准、目标打印机或临床验收通过。

## 可用行为

- 在报告的“图条设置”中集中设置全报告 A4 输出，不在每个事件筛选页重复展示全局控件。
- 时间标尺提供“完整区间适配”（既有报告默认行为）与“固定纸速（连续分段）”。固定纸速支持 12.5、25、50 mm/s，175 mm 波形宽度分别容纳 14、7、3.5 秒；超出时连续分段，保留原选区和采样坐标。
- 分段边界按当前导入的 200 Hz 样本对齐，心搏归属采用左闭右开区间，避免重复计数。至少 5 搏要求针对完整入报区间，不是每一张分段。
- 网格、心搏类型／HR／RR 标注开关作用于网页 A4 预览与 PDF。关闭标注不隐藏导联名称、时间、时长和幅度单位。
- 1–3、4–6、7–12 导联分别占 1、2、3 个纸面槽位；HTML/SVG 与 PDF 使用一致的图条高度、基线和裁切边界，不压扁超框波形制造平顶。
- 时间保留非零毫秒，极短尾段显示实际时长。分段注明本段／全段心搏数量，完整区间警告保留在图条说明续页。
- 不改变报告选图、人工诊断、原始 ECG 或已保存的估算电压快照。更改设置后须重新预览并保存。
- 缺失／null 年龄在 PDF 与网页统一显示“—”，不再打印“None 岁”；数值 0 不被当作缺失。

## 实际链路证据

隔离数据库和纯数学合成病例，不使用患者 ECG。先前浏览器验证保存了 v2（关闭网格和标注），刷新后设置仍在；再保存 v3（50 mm/s、网格与标注开启），A4 预览显示两段各 3.5 秒，分别为 3／4 搏。390 px 下修复选择框被旧规则压到 32 px 的问题，最终为 16 px 字号、44 px 高，页面无横向溢出。1366 px 与 390 px 截图保存在证据目录。

第一次浏览器下载回执超时，但下载文件实际已写入 Downloads，摘要与 v3 导出审计匹配；不把自动化回执超时当作生成失败。检查该三页 PDF 时发现 null 年龄缺陷。本轮修正后重启隔离服务，程序依据变化正常使旧报告复核状态失效为 v4／revision 1；未关闭这一保护。

最终通过真实 HTTP 导出接口取得 v4 草稿，3 页 A4，70,560 字节。响应 `X-Report-SHA256`、下载文件 SHA-256 和导出审计三者一致：

`161ecf50f8e4c072a0446aebb0f6a4f39e0a0b854c215ab30fbf6b9a7df7716c`

三页均已用 Poppler 渲染并目视检查：第一页缺失年龄为“—”；第二页只有一个小时分区是因为合成记录共 30 分钟；第三页按 50 mm/s 连续分段，开始时间 08:11:05.865／08:11:09.365，网格、标签和全段 7 搏说明完整。
