# 报告候选与代表图条

## RR 间期

报告只保留一个“RR 间期”入口，来源可选全部、自动长RR、自选RR。

- 自动长RR：当前有效原相邻RR严格大于2.5秒。
- 自选RR：总览右击保存的有效原相邻RR，不要求超过2.5秒或等于全程最大值。
- 同一RR按两个原始R峰端点及当前病例/来源/逐搏依据合并，可同时带两种来源标签。

重复加入同一RR时定位已有图条，保留其图注、导联、区间和备注。来源候选不因图条合并被删除。来源筛选仅影响查看；取消入报直接移出图条。撤销手选候选与恢复候选遵循原审计记录，恢复不会自动入报。

真正的全程最长RR在报告数值核对入口独立计算和查看。自选图注包含“最长”时仍需满足现有数值核对规则。

旧草稿只读打开不会自动写库；正常保存时合并当前有效依据下同一RR的重复图条，保留第一条已有设置。来源或依据已变化的图条仍按既有失效保护重新核对，不会直接套用旧确认。

## 房颤／房扑

点击候选行或时间只查看。整段候选保存完整起止/类型/复核状态；代表图条独立保存入报波形范围。可以浏览整段的起点、中部或末尾，再选择代表窗口。

默认7秒、至少5个可用心搏；实际心搏数由窗口决定。允许在长片段内选取中段，或保留起止过渡上下文；图条应在记录内并与该候选相交。调整图条不改整段起止。

勾选或应用区间可先存待确认草稿。明确“确认整段并入报”时，同屏核对完整候选范围与代表图条范围后提交；取消保留范围。只检查本次实际输出的候选，不增加全候选逐条确认要求。

未保存范围在离开前处理；已应用结论和设置按既有方式自动保存。保存失败保留原位置和当前内容，重试依据与保存回执会核对，避免重复新增。

详细操作也可在本地帮助页 static/help/af-afl.html 查看。
