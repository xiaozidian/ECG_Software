# 报告图条精确回看与连续核查

## 可观察结果

报告中点击“回看事件”时，按事件 ID 和依据版本查找当前筛选／排序中的准确位置，加载目标所在页并定位原事件。此前仅回到第一页，不在第一页的已选图条可能显示其他候选；现在失效或不匹配会明确报错，不静默替代。

波形上方显示当前序号、总数、事件名称和时间，提供上一条、下一条、加入／移出报告草稿与返回入报图条。连续核查跨越 50 条分页边界；首尾禁用越界操作。返回后滚动并聚焦原图条入口，保留已有图注和选择。

波形加载或读取失败时禁用此导航栏的入报动作，保留重试／继续核查入口；切到连续波形时也使这一动作失效，避免把非候选预览误认为当前候选证据。橙色游标修改仍须显式应用，入报不等于诊断确认。

## 范围和决定

- Python 与浏览器查询采用相同 `locate_event` / `locate_basis` 规则；在时间和亚型筛选、排序后计算位置，不修改索引和统计。
- 从报告回看 NN 图条时可独立采用 NN 浏览序列，不自动把 RR 打印配置改成 NN。既有手动打印／序列选择控件未在此全面重构。
- 回看会切到目标亚型并清除小时／长 RR 分段过滤，不声称恢复原来任意筛选组合；导航文字明确显示“当前筛选”。
- 保留白色证据区、海军蓝框架和青绿控件。导航与波形一起进入视野，左侧列表同步滚动当前行；窄屏按钮换行且不造成整页横向溢出。密集原始波形在窄屏上的细节辨认仍需后续专项验收。
- 未修改诊断阈值、事件识别算法或 A4 导出几何；没有推送远端，没有审核真实患者报告。
