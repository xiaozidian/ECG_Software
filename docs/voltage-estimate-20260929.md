# 估算电压开关与独立报告快照

## 使用与边界

网页顶部新增“估算电压”开关与设置；每次启动默认关闭，初始 `1 u = 1 µV` 只是可修改的假设，不是从 DATA 推断出的真实设备增益。浏览器仅记住系数，不记住开启状态。

开启后连续波形幅度读数按 `mV = 设备计数 × 假设系数 / 1000` 显示并注明估算。允许系数为 0.000001–10000 µV/u；假设零点为 0，采样率、导联映射及设备增益仍未核验。原始样本、自动事件阈值、RR/QT 时间及已有人工诊断不随开关变化。没有设备标定资料，不能保证与临床真实电压结果一致。

报告使用独立快照：打开病例后，在设置中点击“将当前状态用于本病例报告图条”，再保存草稿。关闭开关不会改变已保存报告；要恢复设备单位，须在关闭状态再次应用并保存。估算图条导出提供 5/10/20 mm/估算mV，幅度超框显示警告，可降增益后用 A4 预览核对。网页编排图仍自适应显示，不冒充实际纸面增益。

研究分析可勾选“使用顶部当前估算系数”，计算时复制当时设置。开关关闭时拒绝这一选项并提示开启或取消。结果、报告参数和相关幅度单位注明估算；不会借此确认电极位置、启用 VLP 或给出睡眠呼吸暂停确诊。物理单位已知且经过确认的输入优先使用自身单位，不受假设覆盖。
