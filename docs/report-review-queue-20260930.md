# 入报图条按复核状态筛选

## 医生任务与实现

报告网页编排新增全部状态、依据失效、待完成诊断确认、事件已确认四项筛选，可与左侧图条类型组合。计数覆盖全部已选图条，同时显示当前组合的可见条数；筛选只改变视图，不修改选图、图注、导联、人工区间或打印设置。保持原序号，跨报告子页和片段复核返回时保留同一病例的筛选，换病例重置。

状态优先级如下：

- 原事件缺失、事件身份不匹配、选图依据为空或依据版本变化，均为依据失效。禁止从旧依据直接回看或读取旧图条波形，不以缺失解释为正常。
- 依据有效时，只有事件诊断已确认才进入事件已确认。AF/AFL 还必须逐段确认；整体编辑确认不能替代片段确认，片段确认也不能替代整体编辑确认。
- 其余状态一律待完成诊断确认。提示区分“节律片段仍待复核”与“片段已确认，编辑环节仍待确认”。事件确认始终不代表整份报告已审核。

原事件不可用单独作为类型分组，与“依据失效”状态计数区分，避免同名不同分母。组合没有匹配项时明确说明其他选图仍保留，并提供显示全部入口。失效 AF/AFL 图条保留保存草稿后复核对应片段的恢复入口；其他失效图条说明重新筛选路径。打印模式的“保留”不是可导出认证，失效文字明确标注不能导出。

## 局部交互与外观

沿用现有临床工作台，按钮以文字、计数、按下状态与键盘焦点共同表达，不新增风险配色。桌面状态栏可换行；窄屏按钮 16px／44px，辅助说明 14px。筛选重绘后焦点仍落在当前按钮，结论继续移动原节点而非重建。redesign-existing-projects 用于信息分组，impeccable 用于局部空状态、键盘及窄屏检查，不据技能建议改造全站视觉身份。
