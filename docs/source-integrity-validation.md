# 损坏输入、读取失败与恢复验证

日期：2026-09-29。范围是原始文件结构及读取失败的工程保护，不是信号质量、患者匹配或临床有效性验证。

## 实现

- 统一读取入口检查普通文件、本地可用性及读取前后文件签名。文件缺失或权限／I/O 失败返回 `503 / source_unreadable`；macOS 云端占位继续返回 `503 / source_not_local`；结构不合法返回 `422 / source_invalid`。对外错误不暴露绝对路径。
- DATA 必须非空且为完整的 8 通道 int16 帧（每帧 16 字节）。普通波形读取还核对实际读出的字节数，不以请求时长标注被截短的信号。
- EBI 必须有完整 32 字节头、非空的完整 24 字节记录，心搏采样位置严格递增、不重复，且最后位置落在 DATA 范围内。拒绝用自动排序、丢弃记录掩盖输入异常。
- LPS 必须可解析为 XML、有报告文本和有效记录时间。缺失的源报告计数为未知值，界面显示“—”，不将“未提供”变成“0”。
- 病例详情、波形、研究计算、保存及 PDF 入口拒绝上述异常输入；不清空已有结论、选图、审核或审计记录。原字节恢复后重新核对依据，相同输入可恢复原报告状态；真实内容变化仍按既有来源失效规则处理。
- 病例扫描返回可读病例和 `source_issues`，健康检查提供 `data_issues` 及不可读数量。工作台明确展示问题病例及处理方法，允许“重新检查文件”；其他正常病例仍可用。全部不可读时禁用“开始今日复核”。
- 文件结构检查与信号质量分开命名。工作台窄屏允许本地表格滚动，故障说明和重试操作不再被整页最小宽度挤出屏幕。

## 尚不覆盖

- 结构正确不表示信号可诊断，也不能证明 DATA、EBI 与 LPS 属于同一患者；本轮不验证未知 EBI 头字段，不检测所有有效结构内的静默位损坏。首次引入文件时的摘要本身没有外部可信原件可供比对。
- DATA 与 EBI 同时被截短但仍保持结构和范围一致时，没有可信完整时长或外部摘要，不能保证发现。采集导联位置、增益、采样率及实际时间仍需设备资料核对。
- 前后签名检查不是文件锁或原子快照。计算期间外部截断 memmap 文件仍可能造成操作系统级故障；应使用稳定、受控只读的已完成采集文件。
- 网络盘无界阻塞、根目录权限异常、磁盘满、备份／恢复、真实安装包升级及不同平台仍需单独验收。
- 医学算法的参考标注库对照、设备校准与临床专家验证仍未完成；上述工程测试不提供诊断性能结论。
