# RR / HRV / HRT / DC 数值专项验证

日期：2026-09-28。范围是可复现的工程数值和边界验证，不是临床检出率、预后效能或医疗器械验证。

## 独立参考值

| 输入与边界 | 预期结果 / 实现检查 |
| --- | --- |
| NN 800、900、1000、1100、1200 ms；1000 ms 间期内部落入排除区 | 保留 4 个 NN，均值 1000 ms；SDNN √(100000/3)≈182.57 ms；只计算两个 100 ms 连续差，rMSSD=100 ms、pNN50=100% |
| 5 分钟块只有 60 秒有效 NN | 摘要与详细报告均不计为合格块，不输出该块 SDNN index 或频谱 |
| 600 个 1000 ms NN 覆盖两个完整 5 分钟块 | 两处均计 600 个 NN、2 块，SDANN=0；整块内常量序列的零变异是实际计算值 |
| AF 排除仅 2 秒、短于一般插值缺口限制 | 不跨该区插值成频谱；相邻未受影响的合格块仍可计算 |
| 孤立 V 前 800、800 ms；后 760、770 ms；恢复序列每搏递增 10 ms | TO=-4.375%，TS=10 ms/RR |
| 正常间期从 1500→1250 ms，或从 800→900→1000 ms 渐变超出前 5 个正常间期均值 20% | HRT 排除该事件，不输出看似有效的恢复参数 |
| 20 个孤立减速锚点 800→820 ms / 800→840 ms，其余均为 800 ms | DC 分别为 5 / 10 ms；最后一个恰好完整的窗口计入；5% 浮点边界不误排除 |
| 同一心搏序列插入 P/T/未下传 P 标记 | HRT/DC 及 RR 配对不被误断开；伪差 X 则保持断点 |
| RR 非有限、非正、布尔值或字符串；采样时间重复、逆序或不符 | 不纳入有效 NN，不崩溃或生成无限值 |
| 窗化后单边 PSD 的 0 Hz 点 | 与直接 DFT 的功率一致，0 Hz 不倍增 |
| 全程标注 AF、逐搏仍为 N | NN 极值候选归零，RR 极值候选仍可供复核；极值依据变化，不能沿用旧选择 |

实现与自动化：`ecg_core/rr_quality.py`、`static/js/rr-quality.js`、`tests/test_rr_quality.py`。HRT/DC 同时保留原合成数值测试；上述包含独立公式参考值，不以两端一致作为唯一正确性证据。

## 性能观测

纯合成、Node v26.0.0、当前开发机器的单次微基准：

- 20,000 个值计算标准差：旧二次复杂度实现 2020.76 ms，均值只计算一次后 0.54 ms；结果逐数值相同。
- 100,000 个 NN：摘要 41.58 ms，分窗时域统计 69.50 ms；两处都计入全部 100,000 个 NN。
- `node scripts/benchmark_rr_quality.js` 可重跑。耗时随设备、负载、JIT 而变，不等同页面加载、波形下载、频谱全流程或真实医生设备体验。
- 另有按数组实际遍历量约束的回归测试，防止恢复到嵌套全数组均值计算；不使用易抖动的固定毫秒阈值作为测试门槛。

## 未覆盖的证据

尚缺独立临床标注集的误差与失败率、不同设备采样与校准、复杂心律和伪差场景的专家复核。当前标注 AF/AFL 区间统一采用保守排除，待复核候选也会降低有效覆盖；医生排除错误候选后应重算。该策略是公开的工程选择，不声称复现医院软件的全部内部规则。

主报告全记录摘要与 HRV 所选 24 小时窗口的时长可能不同，尤其多日记录；比较数值前必须先比较时间范围。所有缺失与质量不足仍使用空值及原因，不冒充正常结果。
