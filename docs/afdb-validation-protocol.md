# AFDB RR 候选基线对照协议 v1

协议在查看本轮结果前固定。目的：对应用当前 `rr-irregularity-v2` 做可复现、全记录、时间加权的公开节律标注对照；本轮不依据结果调整阈值。后续使用过这些结果的优化不得将本库重新称为未见测试集。

## 来源与输入边界

- [MIT-BIH Atrial Fibrillation Database 1.0.0](https://physionet.org/content/afdb/1.0.0/)，Moody GB, Mark RG. *A new method for detecting atrial fibrillation using R-R intervals*. Computers in Cardiology 10:227–230 (1983)；DOI 10.13026/C2MW2D，ODC-By 1.0。保留引用和来源；不发布原始文件，不读取或上传本地患者数据。
- 下载 25 条记录的 `.hea/.atr/.qrs`、两份可用 `.qrsc`、RECORDS、notes 和官方 SHA-256 清单；逐文件校验。当前生效的 07859.qrs 已由发布者对齐，不读取历史 `.qrs-`。
- 主结果采用头文件有正时长的全部 23 条记录和自动 `.qrs`；00735、03665 的头文件时长为 0，列为无法确定完整域的排除记录，不从末次 R 峰或“约 10 小时”猜测时长。不是按算法表现挑选病例。
- 05091、07859 的 `.qrsc` 单列附加结果，并与同记录 `.qrs` 做配对比较；不混入主集合当成额外病例。
- `.atr` 人工节律作为参考：AFIB 为目标；AFL、J、N 作为非 AF 并分别报告。N 表示其他所有节律，不代表全部为正常窦性。首个明确标注之前属于未知，未知不当阴性。未知标注或逆序／越界使验证停止。
- `.qrs/.qrsc` 不区分心搏类型。输入全部 N 仅为 RR 层适配，不证明正常搏，不利用人工 AF 标签构造输入类别，也不代表应用逐搏分类准确率。未读取波形，不能检验噪声／P 波；官方记录的缺失数据块未被算法从波形识别，保留在记录限制说明中。

## 算法与时标

调用现有浏览器 `screenAFResult`，不在 Python 复写检测器。250 Hz R 峰时间最近邻映射至 200 Hz 整数位置（半值向上），RR 从映射后相邻位置重算，首搏 RR 为 0；不重采样信号、不改变参考节律的原始 250 Hz 时间。记录最大位置误差。映射后重复或逆序时间戳使验证停止，不静默去重。

固定从记录 0 秒开始的 30 秒半开窗口。完整窗、20 个有效 N-N、90% 有效率、25 秒覆盖及 CV／RMSSD／转折率规则均保持发布版本。末尾不足 30 秒属于未评估。保留每窗输出、质量原因、候选与连续特征及源文件摘要。

## 预定指标

1. 按窗边界与人工节律区间精确求交，以**秒**计 TP、FN、FP、TN、未评估 AF、未评估非 AF、未知参考时间。混合窗不删掉，按实际重叠时间贡献。
2. 条件灵敏度 TP/(TP+FN)、条件特异度 TN/(TN+FP)、阳性预测值 TP/(TP+FP) 仅针对有参考且已评估区域。
3. 同时报告总体已评估覆盖、AF 可评估覆盖、全参考 AF 时间候选覆盖 TP/(TP+FN+未评估 AF)；后者是漏检／弃权负担，不把未评估称为阴性。候选负荷减参考 AF 负荷，以已知参考总时长为共同分母；候选负荷并非临床确诊负荷。
4. 额外列出整窗单一参考节律的窗口分类计数、跨节律窗／未知窗数和按 AFIB/AFL/J/N 的秒数分层，便于区分房扑及其他节律错误。
5. 逐记录、全部记录汇总、记录级条件指标均值并列；零分母输出 null，不以 0 或 100% 代替。相邻窗口高度相关，本轮不生成伪独立置信区间或临床合格阈值。
6. 基线结果无论优劣均记录；运行成功只代表输入／实现与统计协议执行成功，不代表临床性能合格。记录算法、适配／评价脚本、协议、输入 SHA-256、依赖版本与运行异常。缺文件或不支持输入停止，而不是跳过。

## 重跑

用独立验证环境（requirements-validation.txt），不改变应用依赖：

```sh
python scripts/validate_afdb.py --fetch --data /path/to/afdb --output /path/to/new-results
```

再次运行可省略 `--fetch`，仍验证全部官方摘要。输出目录必须不存在，包含 summary.json、records.json、windows.csv 及算法／协议／脚本快照。不得把本研究结果等同目标设备的前瞻性验证、QRS 检测验证或临床可用性批准。
