# ST-T复核与报告使用说明

本文说明软件操作与数据含义，不规定疾病诊断阈值。

## 复核与保存

工作台同页显示12导联趋势、复核队列和原始波形。ST、ΔST、T按钮只切换趋势指标；1、3、12导联按钮只切换当前查看，不会把12个查看导联都当成异常导联。实际复核导联在复核栏中选择。

选择机器候选或“自选区间”，设置完整起点和终点。可以输入时钟、用当前位置设为边界，或快速回看起点、峰值和末尾。新对象的医生结果为空，需要明确选择；机器标签不代替医生判断。核对信号质量和波形后，填写必要备注，一次保存。

保存回执区分已复核、历史待定和依据已变化。未见明确改变、伪差、无法判读都能保存和回看，但不计入确认的ST/T异常数。旧版待定记录不会因升级自动变成已复核。

离开仍有修改的页面前处理保存、放弃或留在本页。保存或网络回执不确定时保留当前内容，并按提交标识核对结果，避免重复创建。再次编辑已有记录保存为该记录的新版本。

## 完整事件、测量范围与代表图条

持续ST/T候选以连续有效支持达到60秒为下限，保存实际结束时间；可能是1分钟、数分钟或更长。不同导联分别判断质量；缺失支持会打断连续性，不用插值填成正常或异常。自动边界受实际测量分辨率限制，人工游标的5ms步长不代表自动边界有5ms精度。

确认整段机器候选时保留整段起止及其测量方法。附加的范围均值、当前ISO/J点和ST60/ST80点测量有各自范围与协议，不会用短测量覆盖整段。自选整段是医生选定范围的记录；软件不凭范围均值证明全段连续异常。短于60秒的记录仍可保存为点/短段复核，但不生成持续事件表行。

报告的代表图条默认7秒并满足可用搏数规则。默认12导联；最快心率、最慢心率和RR图条默认3导联。修改代表图条的导联或区间不修改完整ST/T事件的起止。每张图条都指向真实来源范围。

## 报告筛选

保存后的“报告筛选”定位本次记录。ST-T分组包含ST事件、T改变、复核记录及待处理；点击行或时间只查看波形。

| 用途 | 作用 |
| --- | --- |
| 表 | 在ST/T事件明细表采用符合条件的完整事件；有相应完整测量依据时才可选。 |
| 文 | 在报告的ST-T复核记录中采用该条判断、时间范围及医生备注。 |
| 图 | 加入一张代表波形；取消后直接移出图条，不删除原复核记录。 |

三项独立选择。勾选用途会启用对应报告页；之后关闭报告页只影响本次输出，已保存设置仍保留。表格和文字无需先创建一张图条。正常或无法判读等记录可用于相应文字/波形参考，不会借此增加异常统计。

修改复核后，该记录的旧用途和旧图条会撤下；原图注、导联、范围和备注保留供重新选择，不会自动认可新判断。与该条无关的记录保持原采用状态。失效用途可以明确撤下，不能由软件静默换绑到新依据。

## 报告内容与统计

ST分析页与T波幅趋势页分别在一张A4中显示12导联及共同时间轴、心率。ST默认表示相对等电位线的ST水平；需要时可在报告内容设置选择相对参考的ΔST。T波幅使用自己的指标，不借用ST值。

事件明细分导联列出完整范围、实际持续时间、有效搏均值、极值及其时刻。有效搏数来自该范围实际可用测量，不能用16秒块中位数的平均代替。最大下降、上升及参考代表搏使用真实源样本；参考代表搏不等同ΔST参考基线，也不是合成平均搏。缺失波形明确显示不可用。

全记录已确认的分导联事件数、重叠时段组和时间并集分别统计，不把多个导联的重叠时间相加成总时长。少选明细行或代表图条不会减少全记录确认统计；所选数量另行显示。ST与T分开统计，不以ST事件数替代T改变。

当前幅度未标定时统一使用设备单位u，不自动换算为mm或mV。没有定义或没有有效测量的斜率、幅度、质量和代表搏显示缺失，不以0代替。报告中的这些工程测量不自动形成缺血等疾病诊断。

## 审核与升级

审核检查模板编辑和本次实际采用的ST-T记录、图条及文字依据。未采用的机器候选或历史待定记录不增加逐条审核关卡；不另做“全部ST-T确认”。

修改来源、心搏、测量方法、范围或相关节律排除依据可能使原记录失效。系统保留医生原记录、文字和选图，要求核对受影响内容。算法升级会改变分析来源身份，旧审核状态不能沿用；软件不会自动重新确认、签署或将旧范围推定为连续阳性事件。
