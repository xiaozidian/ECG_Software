# 房颤／房扑图条的逐段确认状态

## 改进

待复核房颤／房扑片段可以进入报告草稿，既有审核门禁会拒绝未确认片段，但原先图条本身没有显示该状态，容易把入报或整页心搏复核误解为片段诊断确认。

现在网页报告编排、导联／区间调整页、A4 预览与 PDF 均逐条显示：

- `房颤／房扑片段待复核 · 非确诊`；缺失或未知状态也按待复核显示。
- `房颤／房扑片段已确认 · 不代表报告已审核`。
- 已排除片段防御性文案为“不应入报”；正常业务路径不提供已排除片段选图，旧选图由依据校验阻断。

可编辑图注不能替代上述状态。整页心搏诊断状态也不能提升片段状态。网页左侧图条筛选分别命名“房颤”和“房扑”，不再使用相同的通用事件名。

JS 与 Python 使用同一状态文案契约。纸面为 AF 类图条状态行预留 4 mm，仍保留原有心搏数、导联、延长时间窗提示、走纸速度和未校准说明。非 AF 图条布局不变；多页固定纸速片段每一段均保留状态。

本轮未改自动房颤阈值、心搏分类、原始采样、确认流程或真实病例。片段确认不是报告审核，软件测试也不是临床有效性验证。
