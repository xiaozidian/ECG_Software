# 最快／最慢心率候选定位点间隔筛选

完成日期：2026-09-30（Asia/Shanghai）。本轮改善候选核查效率，不修改自动诊断算法或宣称临床有效性。

## 使用

报告的最快／最慢心率页新增“定位点间隔”：全部候选（默认）、至少 7 秒、30 秒、60 秒。默认保留每个 RR / NN 序列原有最多 200 条候选，短记录按实际条数显示。间隔是候选定位时间之间的距离，不保证最终图条无重叠；人工延长区间或至少 5 搏的自动延长仍可能重叠。

在当前序列与时间筛选内，按原候选极值排名依次保留：最快优先最短 RR，最慢优先最长 RR，平局使用采样位置和事件 ID 稳定排序。只有与已保留的同序列候选至少相隔所选时间的点才显示；RR 与 NN 独立。此为极值优先的贪心显示筛选，不是最大数量无重叠集合，也不是在全记录中重新补足 200 条。

改变从快到慢／从慢到快的显示顺序不改变被保留的候选集合。先做小时筛选，再做间隔筛选，最后分页；时间范围外的点不会压制范围内的点。比较使用采样位置（当前导入假设 200 Hz），正好等于指定间隔的点保留。

列表明确显示筛选前条数、当前条数与暂时隐藏条数。“全部候选”或“清除筛选”恢复。柱图保留未按间隔精简的分布，分类计数、诊断依据、已选图条和报告设置不变。按 ID 读取已入报图条不受这一显示筛选影响；回看事件或恢复待应用游标时自动将间隔置零，再精确定位原事件，不跳到其他候选。

控件沿用工作台样式；窄屏原生选择控件为 44 px / 16 px，规则用可展开说明保留，当前计数始终可见。没有改变报告纸面。
