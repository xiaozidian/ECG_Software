# QTDB 端点组件验证与歧义保护

完成日期：2026-09-29。结论：**完成可重跑的公开人工标注对照，修复崩溃和部分歧义输出；没有达到可独立用于临床的自动 QT 测量证据。** 不把本次功能回归或误差统计作为医疗器械临床验收。

## 输入、拆分与范围

使用 [PhysioNet QT Database 1.0.0](https://physionet.org/content/qtdb/1.0.0/) 的全部 105 条记录，官方 SHA-256 逐文件验证。采用人工审校 `.q1c`，另对可用的 11 条 `.q2c` 做附加对照，不用自动 `.pu` 标注充当真值。原始论文：Laguna P, Mark RG, Goldberger AL, Moody GB. *A Database for Evaluation of Algorithms for Measurement of QT and Other Waveform Intervals in the ECG*. Computers in Cardiology 24:673–676 (1997)。数据许可 ODC-By 1.0；原始波形没有加入本软件的患者数据库。

首次看误差前固定[评估协议](qtdb-validation-protocol.md)：按记录名哈希拆分，25 条开发组、80 条评估组。只在开发组排错；最终算法快照固定后才运行评估组，没有根据评估结果继续调参。两组来自同一数据库，不等于独立机构外部验证。

使用官方 WFDB 4.3.1、SciPy 1.18.1、NumPy 2.5.3，250 Hz 重采样到 200 Hz 后调用应用实际 `delineate`。验证依赖在独立环境中，不加入临床应用的安装依赖。主标注共解析到 3,528 个 N 标记，其中 3,454 个具备完整 Q/T 参考；每个导联各算一行，共 7,056 行，经预先固定的 RR／边界条件后尝试 4,608 行。

这是**单搏端点组件**检查，不是完整八导联中位心搏 QTd、自动 QRS 检出或 QTc 临床验证。人工参考由专家同时看两导联确定，并非逐导联真值；两个导联分别与同一参考对照，不择优导联。稀疏参考 N 的相邻标记不能证明中间不存在未标注心搏，因此 RR 筛选不等于完整正常心搏筛选。起搏、复杂 ST-T 形态和参考时间网格也会影响误差。

## 发布的变化

1. T 波最大值落在搜索窗口末端时，旧版会对空斜率数组求最小值并触发异常；新版返回明确质量失败，可换窗或人工复核。
2. 两个同向显著波瓣之间持续回到基线时，不再直接把最后一瓣认作 T 终点，也不自动截断为前一瓣；提示 T/U 或后续波歧义，交给人工端点。
3. 保留异向末支，避免将 ST 压低后真正的正向 T 波或双相 T 波截掉。该规则仍不是通用 T/U 分类器，融合波等情况没有因此得到解决。

算法版本：`research-2-qt-ambiguity`。源文件 SHA-256：`58a1ca7394d8420b0cd9c30b3d276a582b23294da5757ea34fe4ed72c62d14f5`。版本变化会让原有人工端点依据失效，须重新复核；不改写原始 ECG。

## 主结果

覆盖率分母为满足固定参考／RR 条件的“导联 × 心搏”尝试数，不是全记录全部心搏；误差只对有自动结果的行统计，必须与覆盖率一起阅读。

| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 开发 25 条 / 旧版 | 1,230 | 672 | 54.63% | 1 | 48.451 | 38 | 132.45 | 239 |
| 开发 25 条 / 新版 | 1,230 | 665 | 54.07% | 0 | 47.672 | 38 | 129.8 | 232 |
| 评估 80 条 / 旧版 | 3,378 | 1,960 | 58.02% | 0 | 48.430 | 38 | 130.0 | 617 |
| 评估 80 条 / 新版 | 3,378 | 1,927 | 57.05% | 0 | 47.455 | 38 | 118.7 | 598 |

新版评估组的 Q 起点 MAE 为 24.222 ms、T 终点 MAE 为 36.701 ms；QT 有符号偏差 −20.810 ms、标准差 63.320 ms。50 ms 仅用于排错分层，不是临床合格阈值；同记录／相邻搏不独立，未计算或宣称临床置信区间。

**不能将 MAE 的下降解读成定位精度提高：** 两版共同输出的开发组 665 行及评估组 1,927 行，端点完全相同。新版只是将原本输出的 40 行转为人工复核，其中开发组 7 行、评估组 33 行；后者有 19 行旧版误差 >50 ms，也有 14 行不超过该排错阈值。新增规则合计提示 170 行歧义，其中 130 行此前已因其他质量原因被拒绝。这是保守质量保护，以少量自动覆盖率为代价，并不是自动准确度突破。

全 105 条主标注合计：新版 2,592 / 4,608 行输出（56.25%），0 次算法异常，成功输出 QT MAE 47.510 ms。仍存在起点误选、基线偏移、ST-T 形态和下一波混淆，不应跳过人工端点复核。

## 未采用的方案与附加检查

- 首个自动 T/U 截断方案：开发组输出 737 行，QT MAE 52.881 ms，比旧版更差；错误图显示 ST 压低后真实 T 末支被截断，未采用。
- 加入异向保护的自动截断方案：输出 697 行，QT MAE 48.286 ms；共同输出 668 行的 MAE 变化仅 −0.022 ms，还存在个别大幅退步，仍未采用。
- 最终选择“歧义拒绝 + 人工端点”，没有把上述失败候选覆盖或删除。
- 第二标注者 `.q2c` 的 11 条记录：404 个 N 标记、402 个完整 QT 参考、472 行尝试、291 行输出（61.65%）、0 次异常、QT MAE 54.773 ms。包含开发和评估记录，只作为附加对照，不是额外独立样本，也没有与主标注混合求均值。
- 新增 7 个形态回归用例：正／负极性分离 U 波、正／负极性双相 T、正／负极性 ST 压低后异向 T，以及窗口末端；另有 5 个协议／标注解析／缺失值／拆分测试。合成通过不能代替上述真实误差结果。
- 最终专项 25 项通过、完整套件 404 项通过（退出码 0；收集数另核对为 404），`git diff --check` 通过。首次专项出现一次 API 400/409 不一致，独立及最终完整复测未重现，根因未确认；断言现附带响应正文以便追踪。评估本身没有删除异常或失败样本。
