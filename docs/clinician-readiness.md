# 医生可用性验收矩阵

更新：2026-09-30。目标是医生能够完成一个真实病例的复核、修订、选图和报告交付，不以“页面能显示”代替闭环验收。

## 当前结论

当前具备本地复核工作台、人工心搏／节律编辑、修订后统计、研究测量和报告编排导出。已有自动回归及有限的浏览器任务验证，但尚不能把这些证据表述为已完成临床有效性验证或正式部署验收。以下分开记录工程能力与尚欠的证据；“已实现”不表示已完成专项临床验证。

最新房颤外部验证：冻结 AFDB 开发参数后，在 LTAFDB 全部 84 条、1,960.6 小时记录上评价。自动 QRS 输入的熵候选将 AF 时间捕获由 85.25% 提高至 87.39%，误提示由 174.784 h 减至 54.300 h；但记录宏平均捕获由 83.18% 降至 82.16%，9 条记录下降超过 5 个百分点，05 的短 AF 完全漏提示。112 的自动 QRS 输入整段未评估，不是阴性。**未替换生产算法，不能宣称临床可用**。3,528 项原始网格审计零差异、988 项软件回归通过；下一步解决短事件聚合与输入覆盖失败，而非仅优化汇总指标。详见[外部验证与失败定位](ltafdb-validation-20260929.md)；此前[AFDB 开发实验](af-entropy-development-20260929.md)保留供追溯。
