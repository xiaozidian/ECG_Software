# 公开标注驱动事件统计核对 · 2026-09-29

## 结果与修复

原实现只识别固定起点的重复周期，例如 NVNV 可识别、VNVN 会漏识别；足够长的周期也会丢弃符合模式的尾部。已改为支持所有循环起点的线性扫描，保留符合周期的尾部，且同一模式内片段不重叠；噪声和其他类型不会被删除后拼接。保留至少两个周期的既有纳入长度。

使用预先固定的[协议](mitdb-counting-protocol.md)，对 MIT-BIH 全部 48 条当前 `.atr/.hea` 校验官方 SHA-256 后运行。有效 QRS 标注共 109,494 搏；参考标注直接输入统计层，**不是自动诊断准确率测试**。当前逐类计数与官方历史整条记录表没有差异。

- 修正前：23 / 48 条记录存在与规定周期口径的差异，共 277 个失败检查。检查间重复关联，不是 277 个独立缺陷或误诊。
- 修正后：48 / 48 条记录零差异，完整 Python/浏览器索引一致；事件范围、目标心搏、分页、时间柱状筛选、小时表和全程汇总按协议通过。
- S/V 连续段分组数量完全未变；长 RR >2.5 s 为 84 个，>3 s 为 35 个，200 Hz 时间戳映射前后相同。此处长 RR 是标注间期阈值结果，不证明真实停搏。

## 测试中的失败与限制

最终完整回归 **578 项通过**（140.34 秒），比此前 540 项新增 38 项周期与验证适配测试；1 条警告来自既有重复 ZIP 拒绝测试。静态演示重建后专项 5 项通过（1.31 秒），生成的 `clinical-analysis.js` 与源码逐字相同，JS/Python 语法和 diff 空白检查通过。正式 8765 服务按原配置重启，健康检查 status=ok，10 例可读、不可读 0；未自动刷新用户页面或改写正式患者报告。本次未改变页面布局，未声称新增视觉或物理打印验收。

新增测试先在原实现复现失败。修正后的首次专项发现三个测试输入/调用错误：将末搏放在右开区间结束点、未以审核模式调用失效校验、错误认为 360 Hz 的 0/1 两点映射后碰撞；修正夹具而非放宽产品规则。另有一次既有真实文件 API 用例返回缺失 `total` 字段，首次未保存响应，根因未确认；补充状态/响应断言后复测通过，不将重跑通过声称为已修复偶发故障。

原始公开标注和头文件留在独立临时验证目录，没有读取或修改正式患者报告。验证脚本不下载 ECG 波形。QRS 检测/自动分型、医生节律判读、真实长 RR 的质量排除、目标设备和真实工作流程仍需独立验证。本记录不能作为“医生可直接临床使用”的证明。
