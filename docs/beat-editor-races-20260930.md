# 心搏编辑异步对象保护与确认窗口

## 结果

改型、预览、右键菜单和确认窗口现在绑定发起时的病例、病例加载批次、页面、操作上下文、内部目标集合，以及模板编辑页可见的选择集合与焦点。等待期间发生变化时，尚未提交的操作停止并提示重新核对，不把旧选择套在新病例上。

已经发出的 PUT 仍属于原病例，不能假称取消或回滚；返回时若页面对象已变化，不重新加载另一病例、不清空新选择、不把旧结果作为当前修订提示。重新打开病例可核查原操作的修订历史。此项不提供服务器事务取消能力。

## 实现

- `static/js/beat-editor-ui.js`：统一操作快照、读取前后检查、固定请求病例、确认窗口代次、提交锁；`quickEdit` 在改变上下文前检查占用状态；提交后的异步刷新核对病例加载批次。
- 页面点击会在编辑器闭包之外更新选择，因此单看内部 `selected` 不够。保存时分别比较两组集合各自的快照，不错误要求两组本来就必须相等。根据当前编辑页面捕获状态，也覆盖从通用命令入口发起的动作。
- `static/css/beat-editor.css`：仅在不大于 580 px 的确认窗口扩大按钮至至少 44 px，说明及表单字号 16 px，底部可换行。保留原桌面布局、波形与分类颜色。
- 静态演示 JS/CSS 同步，入口缓存版本已更新。源码和演示脚本 SHA-256：`24cf78d7084b48faeafc5ae9e6fef43f492b169d5be309ef15468400ffbf7553`。

## 可复现验证

`tests/browser_beat_editor_races.cjs` 在 VM 中加载完整实际编辑器模块，以延迟传输和最小 DOM 桩复现竞态；不是在真实患者页面注入脚本。`tests/test_beat_editor_races.py` 运行 45 个场景：读取、预览、提交返回、通用命令、菜单、确认、撤销；覆盖换病例、同病例重新载入、换页、取消、替换窗口、改变选择或焦点，以及正常成功路径。

- 本轮重新执行在途测试先得到 **6 失败、31 通过**，证实页面外部选择／焦点变化尚未受保护。
- 加入快照后扩大到 45 个场景，专项首次 **4 失败、127 通过**：通用命令固定使用 review 上下文，即使从编辑页调用。改为按当前页面捕获可见选择，没有删除用例或放松断言。
- 最终编辑、修订后报告、出现记录渲染专项 **131 通过（18.90 秒）**。
- 最终完整回归 **1,147 通过（199.27 秒）**；1 条既有重复 ZIP 条目警告，用于验证备份拒绝损坏包。
- JS 语法、差异空白及两个静态镜像比较通过。正式 8765 提供的编辑器脚本摘要与源码相同；没有刷新用户标签页。

## 浏览器任务验证

使用独立 8766 服务、独立数据库、两例 2 分钟纯数学合成输入，不对应真实人员。第一例从此前测试 r3 开始：右键 1.700 秒正常搏、预览改为 S、确认保存至 r4；下一卡片按 V 至 r5；撤销至 r6，正常搏集合恢复。之后预览 2.915 秒改型，桌面与窄屏检查后取消，未新增写入。第二例仍为 r0。

1366×900 和 390×844 的最终截图见 [验证目录](validation/beat-editor-races-20260930/README.md)。窄屏 dialog 宽 352 px，内容宽／滚动宽均 350 px，三个按钮高度均 44 px。首次动态缩放截图出现浏览器合成缩小，刷新隔离页面后重新核对并保存真实窄屏截图。浏览器 error/warn 日志为空。桌面确认表保留目标时间、受影响数以及有效心搏、NN、最长 RR 和非心搏标记前后值。

验证后关闭临时标签页、停止隔离 8766 服务；正式 8765 保持健康（10 例可读，0 例不可读），保留用户原有标签页。

## 边界和下一步

这些证据证明已覆盖场景的编辑对象和刷新保护，不证明全站所有并发路径或临床诊断准确性。未修改识别阈值、原始患者文件、正式报告或远端仓库。浏览器实际任务未注入延迟，竞态由可重复 VM 测试覆盖；目标医生设备上的真实慢网络、任务耗时、误操作恢复仍需验收。

下一步将人工改型后的当前焦点恢复、候选筛选和报告证据失效放在同一医生任务中测量，持续核查对象与依据是否一致；设备标定、独立算法性能和整体临床验收仍未完成。
