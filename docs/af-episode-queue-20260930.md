# 房颤逐段复核队列与输入保护

## 本轮交付

房颤／房扑页原先一次生成所有片段行，切换片段重建表单；大量候选时难以连续核查，未保存输入也会丢失。现在保留现有临床工作台视觉，增加：

- 全部、待复核、医生确认、已排除、本地未保存筛选，各自显示数量；按开始时间、结束时间、ID 稳定排序，每页最多 20 行。
- 波形上方的上一段／下一段、回看起点／末尾、编辑片段和返回列表。确认后当前片段移出待复核集合时仍显示原片段，明确说明不在当前筛选内，下一段按时间继续，不自动确认其他片段。
- 起点前保留波形上下文，定位标记绑定实际事件边界；末尾按右开区间处理。导航等待时切换病例、源数据、修订、片段或退出房颤页，旧导航不抢焦点。
- 表单输入按病例与片段暂存于内存，翻页、筛选、前后段导航不清空；筛选不重建同一版本的编辑表单。关闭／刷新有未保存提示，但不声称输入已持久化。
- 修订变化时保留旧输入供查看、禁用覆盖保存；片段被移除后仍可在“本地未保存”中找到输入。放弃输入需确认且受修订保护；保存成功后立即清理已确认保存的草稿及计数。

浏览和筛选没有写入诊断的副作用。保存仍经过明确确认、后端修订检查和可撤销历史；原始采样只读。生产 AF 筛查算法、阈值、负荷分母和报告规则不在本轮改变。

## 验证

- 21 个新增场景执行实际发布的 JS 函数：1,200 段分页、排序不改源数组、空筛选、状态变化后的前后定位、特殊 ID、草稿保留／隔离／撤销、移除片段草稿，以及病例／心搏／节律／源对象／页面／导航竞争。
- 本轮发现保存后草稿计数晚一轮刷新的问题，已把保存内容核对放在队列计数之前，并新增同一轮计数和行标记断言。
- 首轮全量 14 failed / 1,242 passed：旧表单测试提取渲染函数时没有带入新队列依赖，均报 `rememberEpisodeForm is not defined`。更新测试夹具以加载实际依赖并提供命名表单控件；原有“人工修订不会被重筛覆盖”、状态保留、过期版本拒绝和存储撤销断言全部保留。
- 修复后房颤质量、队列、覆盖专项 **106 passed / 8.11 s**；完整回归 **1,256 passed / 208.76 s**，一条既有重复 ZIP 警告。
- 隔离数学合成病例的 1,200 条记录：一次实际创建的表格行从 1,200 减至 20。仅是 DOM 数量改善，不冒充整页延迟实测。原始端到端流程验证了导航后备注保留、确认保存，以及确认后在待复核集合继续定位。
- 最终浏览器确认：待复核 399 段、20 页，每页 20 行；键盘 Enter 前进至第 2 段，波形加载完成。1366×900 桌面与 390×844 窄屏截图，无整页横向溢出；新增窄屏导航按钮 16 px 字号、44 px 高度。浏览器 error/warn 为空。截图与数据来源见 [验证说明](validation/af-queue-20260930/README.md)。
- JS 语法与 diff 空白检查通过。源码 JS/CSS 同步至静态演示。未修改真实患者记录或报告，未推送。

## 设计取舍与限制

Impeccable 的硬化／Operate 指引用于异常状态、焦点和窄屏；redesign-existing-projects 用于现有系统内的层级与定向改进。保留系统字体、紧凑密度、数据色和青绿操作，不采纳装饰性换肤或动效。既有 detector 给出了颜色／字体等建议；移动控件 16 px 是可读性选择，不通过缩小文本消除建议。未重跑全局设计配置或宣称全站无障碍通过。

这不是临床可用性认证。压力测试事件为极短的人工构造片段，不代表临床 AF 定义，也不用于测量检出性能。现有自动筛查的短事件漏提示、早搏／伪差误提示、未评估输入以及真实设备标定仍需独立验证。下一步需测量医生连续核查的任务耗时、漏复核和误操作率，并继续加强波形质量证据。
