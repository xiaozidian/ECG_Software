# ST-T 候选计算与升级连续性

保留 .33 的候选形态、噪声和导联背景筛选规则；算法版本仍为 0.5.0，测量方法、阈值、全部原始趋势及房颤独立分析均不变。通过批量布尔字段分配及连续时间轴工作区减少冷计算成本。
