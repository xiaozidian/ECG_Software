# 医生反馈：分段房颤、区间 ST 均值与简化报告

本版在独立工作副本实现，不包含病例、工作数据库、医院素材或私有验收截图。源码身份以本目录 source-manifest.json 为准；工程测试不构成临床有效性验收。旧版发布记录保留在相邻版本目录。

## 操作

- 在总览或模板编辑的底部三导联连续波形右键选择房颤起点与终点。端点绑定原始样本，可跨时间窗；默认待复核，显式保存。保留原心搏编辑与模板双界面。
- ST-T 的点测量继续保留。新增独立区间统计，至少60秒，时间落在当前200Hz配置的5ms网格。计算后先填入复核备注，医生选择描述、核对信号并独立保存。
- 报告去掉审核前检查面板、术语树及高级辅助的默认入口。保留结论、图条、保存、导出与既有数据；已保存的 ST 备注和区间统计在详情中回看，填入报告结论须医生明确操作。
- 未应用区间、未保存文字、冲突、过期依据和未完成医生确认仍限制保存、审核或导出。保存响应丢失后先只读核对固定提交编号，不自动重复写入。

## 区间均值的精确定义

原始格式为本项目既有200Hz、8通道、int16LE导入口径，展示12导联；不将此口径视为设备资料已独立核验。不换算mV，结果使用设备单位u。

选区为半开整数原始样本范围 `[start_sample,end_sample)`，至少12000样本。采用旧 ST 模块相同的固定16秒格、机器J点估计与工程质量门槛。每格至多7个代表搏只用于J点和质量估计；最终均值包括该范围内全部合格候选搏，不平均趋势点、中位数块值或显示降采样。

每搏基线为R前200、180、160、140、120ms五点中位数；ST值为机器J加0/60/80ms周围±10ms五点中位数。先得到逐搏ST减基线，再对所有有效搏取算术均值。原筛查阈值、单点手工ISO/J测量、诊断规则及原波形不改。

显式 AF/AFL 标注的待复核与确认区间均排除；已排除状态不参与遮罩。存储的含末样本区间转换为半开范围，排除也覆盖基线和ST读取支持窗，不重建相邻搏。统计分别给出使用、剔除、缺失及原因；没有有效搏返回null，真实零值保留0。覆盖率只描述工程统计覆盖，不确认逐秒信号质量、窦性来源或连续可用性。

均值为新增描述性统计，机器J、PR替代基线、采样率及导联映射仍待独立设备和医生参考核验。负均值不能单独证明持续下移、缺血或任何疾病；未检出的搏不被补造。至少一分钟是本次医生工作流选区要求。方法差异会影响Holter ST分析结果，参见[2003年原始研究](https://onlinelibrary.wiley.com/doi/abs/10.1046/j.1542-474X.2003.08306.x)；临床背景参见[2017 ISHNE-HRS共识](https://onlinelibrary.wiley.com/doi/10.1111/anec.12447)，本实现不宣称完整符合其临床判断要求。

## 来源与保存

区间统计绑定病例、原始内容、算法版本、心搏修订和全局复核修订；请求的客户端上下文完整返回，实际服务端身份单独给出。报告保存的是完整统计摘要、范围、方法、有效搏数、原因、遮罩及来源摘要；手工点测位置独立保留。底层详细块用于计算和独立复算，不随报告摘要传输。

原生服务为本次实例计算结果签发HMAC凭据；服务重启后未保存的旧凭据须重算。数学网页使用浏览器数学内容摘要，明确不冒充原生服务签名。固定UUID只接受同一保存意图；首次提交后的自身修订+1可核对，后续其他复核修订阻止旧统计被当作当前依据。源文件和工作库分离，SQLite事务内再次核对来源及心搏依据。
