# ST-T 综合形态与持续事件

本版本应用标识为 `0.12.30-stt-comprehensive.20261109`，Windows 分发版本拟为 `1.0.16`。ST 和 T 保持各自的测量与判定；AF/AFL 的新增、编辑、确认或排除不作为 ST-T 时段排除条件。同一来源和同一心搏条件下，节律编辑不得改动 ST-T 数值、候选或医生证据。

识别扩展包括持续 ST 水平偏移与动态 ΔST、持续 T 倒置、T 低平、动态极性反转和双相 T 形态。自动连续事件的最短时长为 60 秒，保留完整的实际起止及持续时间，分钟趋势摘要不代替连续证据。可测但可疑的值保留并标注质量；无法测量处不补零、不跨缺口拼接。

医生一次保存可包含多个导联和多个 ST/T 结论。保存的父记录可在报告 ST-T 筛选中定位，事件表、文字和代表图条用途分别选择；不要求逐条确认全部机器候选。图条长度不等于事件长度，ST-T 图条默认十二导联。旧医生记录及原方法保留，真实依据改变时明确提示重新复核，禁止把旧证明改签成新算法。

当前 DATA 导入口径的设备电压增益、采样与导联映射、滤波响应仍待设备资料核验；筛查参数使用设备原始单位，不能当成 mV/mm 临床阈值。形态候选不是病因诊断。工程合成波形的预设片段不等于临床金标准。

此说明描述实现范围，不代表构建、端到端验收、临床有效性或三端发布已完成。最终版本、源文件指纹、实际验收结果及包哈希由本次交付回执确定。
