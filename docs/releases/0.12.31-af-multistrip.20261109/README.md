# 房颤多图分组与完整 ST-T 复核

同一房颤/房扑片段在入报筛选中保留一行；下方小图栏按起始、段中、末尾或自选位置逐图采用。点击只浏览，取消勾选同步移出报告，整段确认只做一次。报告按完整片段分组，并在每张图注明图序、角色和实际时间；多图不重复增加房颤片段数与负荷。

继承完整 ST-T 分析：ST 压低/抬高、动态 ΔST、T 持续负向、低平、极性反转及双相形态；持续候选以 60 秒为最短时长，保留实际 n 分钟起止。ST-T 与 AF/AFL 诊断状态独立。复核后由报告筛选分别决定文字、表格和图条。

统一源码版本：0.12.31-af-multistrip.20261109。Windows 发行适配版本：1.0.17。数学边界测试与十例本机真实记录工程流程验收分别记录，均不构成有医生金标准的临床准确性验证。电压/设备采样契约仍以当前导入假设为限。
