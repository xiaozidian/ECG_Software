# RR、固定五分钟 HRV 与版本化术语树

本版本新增只读 RR 分类工作台、固定五分钟 HRV 排除区间复核，以及报告术语树。原始 DATA / EBI 不被修改；报告结论、人工修订和诊断确认仍由医生负责。

RR 保留原始相邻 QRS，不把筛选后的 N 搏重新连接。界面区分 N→N 标签对、既有 NN 规则候选和已核实 NN；未知标签、节律、质量和来源不会自动成为正常。RR、比值和心率保留完整匹配计数，波形定位要求病例、修订、双端点和心搏身份完全一致。

HRV 区间使用半开采样范围。预览、应用、撤销、重做、重置、恢复和窗口确认均记录版本；剔除留出缺口，差分和频谱不跨缺口重接。固定 300 秒、至少 30 个 NN、累计 240 秒及 FFT 是既有工程兼容协议，不是临床合格标准。空排除文档保持原严格计算输出。报告引用保存窗口、文档 hash、逐搏及分析修订；过期结果、未应用修改和旧确认不能用于正式审核。主报告的全记录 NN 基线与编辑后窗口的 HRV 专页分别标明来源。

术语条目保存稳定 ID、层级、版本、hash、来源、许可、适用范围和审核声明。导入先预览再确认，同版本不能覆盖；插入保存原文快照，词库更新不改已有报告文字。内置目录仅有六条原创 MIT 草稿用语，不是医院完整词库、SNOMED 库或经过医生核准的诊断目录。

网页数学 Demo 使用明确标注的浏览器计算与本地存储，不读患者输入。其身份指纹不是原始临床文件 hash；保存、确认和导出体验不构成临床验证。

## 方法和验证边界

pNN50 沿用严格大于 50 ms，以有效连续差分数作分母，单位为百分比；SDNN 使用样本标准差。缺失显示不可用原因，不用零代替。LF/HF 不作为自主神经平衡、压力或疾病结论；频带四位小数量化和比值量化误差单独记录。FFT 没有伪装为 AR 或其他估计器。

独立验证包含手算、10000 个种子固定的数学向量、同估计器 SciPy 对照，以及小型许可明确的 PhysioNet 注释 / 官方 WFDB 工具对照。它们验证算术、原始拓扑和软件事务，不证明本设备的 QRS 检出、200 Hz / 导联映射、医院隐含规则、临床灵敏度、特异度或有效性。

主要依据：[PhysioNet HRV 工具教程](https://archive.physionet.org/tutorials/hrv-toolkit/)、[ann2rr 定义](https://physionet.org/physiotools/wag/ann2rr-1.htm)、[WFDB 注释类型映射](https://physionet.org/content/wfdb/10.7.0/lib/ecgmap.h)、[AFDB 注释来源](https://physionet.org/content/afdb/1.0.0/)、[FHIR CodeSystem 版本模型](https://www.hl7.org/fhir/codesystem.html)、[IMDRF 临床评价区分](https://www.imdrf.org/documents/software-medical-device-samd-clinical-evaluation)。FHIR 仅为结构参考，未宣称完整符合 FHIR / DICOM。未从许可未核实的医院或商业词库复制语料。

安装与构建仍使用项目的本机工具，保留旧工作数据库与明确的备份恢复入口。发布包含软件、合成测试和数学 Demo；患者资料和私有验收证据留在本机。
