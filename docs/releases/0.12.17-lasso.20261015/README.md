# 自由套索与散点交互同步

模板密度页及模板库使用闭合自由套索。凹形与自交轨迹按多边形选点，点选只改变浏览焦点；临床改型勾选保持独立。空选保留为空集，重复圈选、清空、Escape、滚动取消及迟到响应均保留既有病例与来源隔离。圆点大小随绘制密度调整，命中范围独立于视觉半径。

生产身份见 [source-manifest.json](source-manifest.json)，共112文件。未修改临床算法、阈值或源波形。公共网页仅构建数学合成输入，既有浏览器工作存储命名空间保持不变。

Windows包装版本1.0.2；在0.12.16全天性能分支上仅合并三个UI文件并更新版本身份，保留请求级来源租约、备份与升级保护。合并后Mac可运行的52项专项检查通过，16项Windows专属检查须由Windows构建机执行。CI保留原2148项并加入1项套索测试；成品Edge验收增加从完整M01 EBI独立计算的凹形套索、多界面、空选、重复、取消及缩放检查。

旧版1.0.1留存。新增版本不表明医院Windows10、签名或临床有效性已验收；实际构建结果和限制随成品证据记录。
