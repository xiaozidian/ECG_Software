# 保存流程与图条右键优化

- ST-T 保存复核、房颤候选保存与删除：已知元数据写入后更新记录及当前窗口，不重建全程逐搏图。
- 来源、心搏、并发或不确定提交变化仍核对完整依据；保留草稿及原提交标识，显示同步失败不重复保存。
- ST-T 表、文、图显示不可用原因，并提供本条“修改复核”入口；不自动重新签认历史记录。
- 报告图条内右击或 Shift+F10 打开与“图条操作”按钮相同的菜单，按钮保留。
