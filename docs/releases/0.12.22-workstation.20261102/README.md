# 0.12.22 工作站交互与 RR 证据读取更新

本版沿用既有 RR、NN、事件与统计口径，改善证据读取和页面交互。

- 最长 RR 数值核对采用自己的自动区间，不再继承其他人工图条的区间。
- 最长 RR 与图条核对复用当前版本的私有事件索引；预览和确认仍重新读取信号并核查来源。
- 闭合散点圈选依据完整路径判断，回到起点时保持圈选结果。
- 保存 ST 标记或完成复核后返回总览，更新配套病例依据，使当前波形右键菜单保持可用。
- 窄窗口中的模板波形工具栏按容器宽度排列，避免时间文字和操作按钮撑出页面。
- RR 候选、是否入报、证据核对分别保存；取消选择和撤回候选时移除对应报告图条，恢复候选保持未入报。

本地真实来源验收证据保存在本机独立工作库。公开构建仅使用软件与数学来源，发布不含真实病例数据。实际发布与逐例验收结果在本轮验收记录中单独核实。
