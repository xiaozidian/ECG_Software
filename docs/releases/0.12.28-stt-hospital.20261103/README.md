# ST-T 医院式复核与报告

应用版本 0.12.28-stt-hospital.20261103；Windows 包装 1.0.13。

- 在同页查看逐导联 ST 电平、ΔST 与 T 趋势及原始波形，分开保存完整事件与短图窗。
- 一次保存医生复核，记录稳定ID、医生结果、导联、范围、备注、点／范围测量协议和来源依据。
- 报告分别选择事件表、正文和代表图条；阴性、伪差、无法判读与点／短段记录不冒充持续异常事件。
- 医院式12导联趋势、逐导联事件统计、时间并集与选用数量使用同一复核记录，不因少选图条改变全记录统计。
- 本次更新了后端与ST算法，Windows真实重建EXE。旧记录、图条设置和医生文字保留；真实依据变化按既有机制标记待重新复核，不在后台重新签署旧报告。
- 数学Demo共用前端和同源数学预计算证据；浏览器不运行完整Python后端。电压标定与未定义斜率不捏造数值。

最终包与测试结果以冻结后的验收记录为准。本草案尚未发布；软件与数学流程验证不代表临床验证。
