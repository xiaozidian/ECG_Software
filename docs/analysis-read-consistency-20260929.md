# 分析读取一致性与失败恢复验收

日期：2026-09-29。范围为 HRV、ST-T、高级研究测量和报告预览的工程一致性；不是新增临床有效性结论。

## 实现

- 新增 `GET /api/cases/<id>/analysis-basis`；以来源／算法依据 `analysis_basis` 和当前复核修订 `analysis_revision` 绑定一次分析读取。病例详情使用嵌套 `clinical_identity`，保留原有根级编辑器修订字段的语义。
- 趋势、RR 图、散点、摘要／详细／分窗 HRV、ST-T 复核、报告统计、报告分节、高级分析及独立 HRV 导出核对读取前后的依据。客户端指定旧依据或计算期间发生变化时拒绝结果，不拼接新旧版本。
- 前端 `analysis-consistency.js` 统一执行“取得依据 → 并行读取 → 校验各项 → 再核对依据”。趋势页整批更新摘要与详细 HRV；ST-T 缓存仅在依据完全相同时复用。
- 开始读取及失败时清空旧图、旧 ST 数值及旧计数；未知值显示“—”，不显示成正常零值。失败提供重新读取，未取得当前 ST 证据时不允许保存注释。
- 病例切换、重开同一病例、旧控件回调及晚到错误均受请求标识保护。背景读取不覆盖未保存的报告正文。
- 研究计算与分节证据整批核对。A4 预览中的病例资料、统计、选中波形和研究页使用同一批依据；报告编排变化或旧窗口结果不能继续导出。独立 HRV 下载也绑定当前显示依据。
- 静态 Demo 实现同一交互协议，但其依据只标识浏览器本地数据／修订，不能解释为原始文件内容指纹。原始采样高级分析仍明确不可用。

这属于读取前后验证与拒绝混用，并非文件系统原子快照、可重放版本库或多用户临床系统认证。

## 仍未解决的范围

- 工程回归和合成 UI 验证不能替代独立算法对照、目标设备校准、医生端完整任务和物理打印验收。

- VLP 仍不适用于当前 200 Hz 采集；ECG 周期性 RR 筛查不输出睡眠呼吸暂停确诊或 AHI。
- 原始文件并发外部修改不具备文件系统事务隔离；本轮没有把所有非临床读取接口改成原子快照。
