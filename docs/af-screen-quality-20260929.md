# RR 房颤候选：质量门槛与重分析保护

## 复现的问题

原 `rr-irregularity-v1` 使用 RR 数字和显示时间分箱，未复用现有采样间距一致性检查。固定 800 ms 的 R 峰序列，若 RR 字段改为不规则数列，旧算法仍能给出 0–120 秒候选；解码实际只有 5 个有效 RR。旧转折率先删除坏点再计算，可能跨缺口拼接；重分析还会替换算法来源的已确认／已排除片段。

这些是软件契约与复核保护缺陷的合成复现，不是已测得的临床假阳性率。

## 实现

筛查仍在浏览器运行，Python 后端负责保存、版本校验与撤销。没有新增独立 Python 筛查副本。

`static/js/overview-engine.js` 的 `screenAFResult`：

- 仅以原始 `sample_index / 200` 为时间依据，范围使用全记录绝对秒数；选择非零起点不再单独平移显示时间。
- 使用共享 `intervalMask`；非 QRS 标记不充作间期，X 两侧、非法数值、逆序／重复边界、RR 与采样距离不符的间期不可用。
- 必须是完整 30 秒窗口，至少 20 个有效连续 N-N 间期，占该窗 QRS 标记至少 90%，RR 为 300–2000 ms，有效间期累计覆盖至少 25 秒。整个间期必须处于该窗内。
- CV、归一化 RMSSD 和转折率的原工程阈值不变：0.12、0.14、0.45–0.85。RMSSD 只用相邻有效间期，转折率只用连续三元组，不跨坏点／早搏／伪差拼接。
- 不完整尾窗或质量不足窗明确标记未评估；提供原因、间期数、覆盖、连续配对数与三元组数。未评估不会输出正常或阴性结论。
- 候选来源升级为 `rr-irregularity-v2`，仍全部是待复核 AF 样不规则候选，不识别 P 波，不自动识别 AFL。

`planAFRescreen` 只替换 v1/v2 算法来源的**待复核**片段，且仅在本轮真正评估的窗口内替换。保留所有已确认、已排除、人工来源、外部来源及未评估区域；新候选避开这些保留片段。连续可评估区域先合并再切分，避免逐窗切分造成额外碎片。保留的医生片段可把候选窗口切成短片段，短片段不代表单独完成了一次 30 秒诊断。

`static/js/overview-workbench.js` 在保存前说明评估／跳过窗口数、拟加入候选数、总记录数及其中已排除数；没有可评估窗口则不发起保存。确认计划绑定病例、心搏修订和节律修订，页面已变化时拒绝旧计划；后端原有版本冲突保护仍保留。

补充修复：编辑器显式保存算法候选的边界、类型、备注或状态时，将该片段来源转为 `manual`，包括仍然选择“待复核”的情况，防止下一次重分析替换医生已经编辑的内容。不会自动升级为医生确认；原来源和内容保留在撤销历史中。新增片段、全程标记与已显示的编辑表单也绑定打开／渲染时的病例和修订，不仅在最后确认框绑定；旧表单不允许对新病例或新版本组装保存计划。已被移除的编辑目标明确拒绝。

## 验证

- 新增 `tests/test_af_screen_quality.py`：31 项，覆盖错误 RR、正向不规则输入、相对显示时间、伪差／S/V 邻接、尾窗、非 QRS 注释、不跨缺口的连续特征、人工决定保护、选区外保留、不修改输入、非法范围、实际 UI 函数确认文案及旧计划拒绝。
- 第一轮完整回归 896 项通过，176.41 秒，1 条既有 ZIP 警告；增加 4 项确认计数／修订绑定测试后，全量 900 项通过（172.56 秒）。
- 先后两个专项运行分别 35 项与 39 项通过；未放宽已有随机不规则、规律、交替、噪声和短数据断言。
- 修正后同一固定 R 峰／错误 RR 复现：候选数 0，可评估窗口数 0，而非“正常”。
- 隔离 HTTP／网页使用 125 秒纯数学信号、独立数据库。实际评估 3 个完整窗，跳过伪差窗与 5 秒尾窗；4 个新候选避开医生确认 10–20 秒及已排除 35–40 秒，旧候选在 60–90、120–125 秒保留。保存后共 8 条记录，医生确认负荷仍为 8%；撤销恢复原 3 条记录。
- 桌面与 390×844 px 确认框可读。首次隔离初始化遗漏既有本地请求头而被 403 拒绝，补齐请求头后成功；没有关闭安全校验。

## 尚未证明的事项

本轮是质量控制、输入一致性和医生复核保护，不证明灵敏度、特异度、AF 负荷准确度或目标设备临床可用性。90%／25 秒等仍是工程筛查门槛，未声称为通用诊断标准。

后续已按固定协议完成 [AFDB 基线对照](afdb-validation-20260929.md)，发现低变异房颤漏提示及其他节律误提示，尚未达到可靠自动诊断能力。[MIT-BIH AFDB](https://physionet.org/content/afdb/1.0.0/) 提供人工节律注释，但 `.qrs` 为未人工修正的自动检测，只有部分记录有 `.qrsc`；结果分开报告输入质量、可评估覆盖与误差，未把自动 QRS 当成全面的人工金标准。公开库也不能代替本设备的信号标定和医生验收；下一步是算法改进与独立评价。
