# LTAFDB 独立 RR 候选验证协议 v1

2026-09-29：在运行候选算法、查看本库性能之前固定。目标为检验冻结的 AFDB 开发候选，不作本库调参或临床批准。

## 数据及来源

使用 [PhysioNet LTAFDB 1.0.0](https://physionet.org/content/ltafdb/1.0.0/)，DOI 10.13026/C2QG6Q，ODC-By 1.0；84 条记录、128 Hz。引用 Petrutiu S, Sahakian AV, Swiryn S. Europace 9:466–470 (2007)；人工复核 `.atr` 标注归功 MEDICALgorithmics Ltd（Warsaw，Michal Tadeusiak 协调）。数据表说明见 [官方标注表](https://physionet.org/content/ltafdb/1.0.0/tables.shtml)。

只下载目录、摘要、头文件和 `.qrs/.atr` 标注，不读取本项目患者资料，不下载全库波形。所有输入验证官方 SHA-256。纳入全部 84 条记录，使用头文件时长；零／不支持时长、异常频率、未知标注必须停下检查，不能选择性略过困难病例。

主输入 `.qrs`：自动 QRS 的 N 仅表示未分类心搏，不是正常搏真值；`|` 是质量阻断点，不是 QRS；`T` 是人工添加的 AF 终止提示，**完全忽略，绝不输入检测器**。

配对输入 `.atr`：人工复核 QRS／类型，仅用于评估输入质量影响。N→N，A→S，V→V，Q→X；不使用节律标签修改这些类别。NOTE 的 MISSB 是“预期但未观察到心搏”的标记，作为质量阻断点，不补造 QRS。必须将配对结果称为参考标注输入，不当作本软件自动逐搏分类性能。

### 实际格式检查补记（任何模型输出之前）

254 个输入文件的摘要验证后，词汇检查发现另外四种 NOTE 内容：`\x01 Aux`（84）、`M`（133）、`MB`（7）、`PSE`（5224）。官方表未解释它们的语义，因此不猜测它们是伪差、起搏或停搏；按明确的 NOTE 非心搏／非节律结构忽略其内容，仅逐记录保留计数。它们不生成 QRS、不修改间期有效性、不成为特征或参考标签。已知 MISSB 仍执行上述独立规则。其他未知 NOTE 继续拒绝。增加全库输入预检，先验证全部记录再运行模型；算法与阈值不因这次格式适配改变。

全库边界检查进一步发现，记录 30 的唯一 `\x01 Aux` NOTE 位于采样点 4,198,064，超过头文件长度 2,826,240；全部实际 QRS／节律注释无越界或倒序。这种明确忽略的 Aux NOTE 可越过终点并另计 `out_of_bounds_aux_note`，不延长时长、参考区间或算法输入。QRS、节律和 MISSB 等其余标记继续严格检查边界。此修订仍在执行任何模型之前完成。

## 输入时标与质量

128 Hz 原始 QRS 整数位置映射至算法的 200 Hz 整数位置：floor((s×25+8)/16)，RR 从映射后相邻位置重新计算。最大位置误差 2.5 ms，报告实际最大值。参考节律保持原始 128 Hz 时间，不随映射改变。

任何跨越 `|`／MISSB 的间期均设 rr_valid=false；阻断点在端点也使该间期无效。不会把质量标记作为心搏插入或跨点拼接。保留真实 R 峰，原始或映射后重复／逆序的心搏位置报错；一般非心搏注释允许相同时间，终点非心搏标记允许在记录长度处。未知符号或 aux 注释停下检查，不静默猜测。

沿用冻结实现的 30 秒窗口、完整窗、N-N、间期 300–2000 ms、≥20 有效间期、≥90% 有效比例和≥25 秒覆盖。熵需连续 12 个有效 RR，缺少时弃权。**不根据本库标签插值、修正 QRS、排除噪声或选择窗口**。

## 固定模型与参考

基线为上轮冻结的 rr-irregularity-v2；另比较 entropy 与 entropy-turning，阈值统一固定 **−1.35**（来自 `docs/validation/af-entropy-20260929/development-v1/summary.json` 的全 AFDB 拟合）。校验该文件及其源文件／快照摘要，拒绝活动算法与冻结源码漂移。不选择本库上的“最好阈值”，不新增平滑或时长过滤。

参考只读取 `.atr` 的节律更改。AFIB 为阳性；官方其余节律 N/SVTA/VT/B/T/IVR/AB/SBR 为非 AF 并分别保留。不把心搏 A 当作 AF，不把 `.qrs` 的 T 当作参考终止；未知参考前缀单列。若实际数据存在未列出的节律，先依据官方定义明确适配再继续，保留修订说明。

## 输出与审计

- 精确半开时间求交，混合窗不删除，未评估不当正常；主输入和参考输入各报告全部记录、时间混淆量、覆盖、条件 Se/Sp、PPV、全 AF 捕获及负荷误差。
- 报告记录宏平均、每条指标、最差记录、候选片段数、FP 小时和不同参考节律下的误提示。没有 AF／非 AF／候选分母时保留 null，不填 0 或 100%。
- 原始 128 Hz 采样网格独立重算全部时间量；适配器测试覆盖类别隔离、QRS 的 T 不泄漏、阻断点、时间映射、终点及未知符号。
- 输入／源码／参数／协议摘要在运行前后检查，结果目录拒绝覆盖；流式保存逐窗特征与输出，附可重放快照。完成后本库即不再是未见测试集。
