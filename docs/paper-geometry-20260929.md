# A4 波形几何与超框裁切验证

日期：2026-09-29。仅使用数学合成信号，不修改正式患者报告；此记录不证明设备电压校准或临床有效性。

## 问题与修正

- A4 浏览器预览的波形 SVG 原先由可伸缩容器决定尺寸。实际合成病例预览测得：760 单位宽 SVG 显示为 716.117 px，210 mm 纸面为 793.695 px，网格折算为 **0.997231 mm**。约 0.28% 的缩小来自占用内容宽度的纸面边框。
- 波形页改用不占布局空间的外轮廓，直接子 SVG 固定 190 mm 宽、自然高度、不参与 flex 拉伸。760 单位对应 190 mm，网格 4 单位对应 1 mm；打印时移除外轮廓。保留窄屏纸面区域横向滚动，不将纸面压缩进手机宽度。
- 原 SVG／PDF 对超框采样点逐点限幅，可能绘制不存在的平顶、改变波形与边界的交点。现在保留采样点原坐标，分别通过独立 SVG clipPath 和 PDF 图形裁切视口隐藏超框部分；不把超框段绘制成边界平线。
- 超框仍明确提示“幅度超框，请降低增益”；裁切不会恢复不可见的波峰，也不改写原始数据。估算单位、未校准说明和真实单位保护全部保留。

## 仍未验证与下一步

- 浏览器 CSS 毫米与 PDF 坐标验证不代替物理打印机在 100% 比例下的实测，也不证明设备 ADC 增益、基线、200 Hz 或导联映射真实正确。
