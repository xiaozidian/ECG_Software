# 工作台入口与索引恢复验证

日期：2026-09-29。范围仅为病例工作台的加载、筛选、开始复核与读取失败恢复；没有更改诊断算法、统计阈值或报告审核门槛。

## 问题与修复

- 初始 HTML 就禁用“开始复核”。索引读取中显示明确状态，尚未取得数据的统计使用“—”。不再让空列表上的按钮可点击却没有反应。
- 页面绑定完成后撤下全屏加载层。设置与备份列表的后台读取不再阻塞病例入口；设置失败也不会把已成功读取的病例标记成失败。
- 列表读取与文件结构检查分别处理。网络／接口失败会移除旧病例行与旧统计，显示中文恢复提示；损坏病例仍沿用原有逐例原因与“重新检查文件”。
- 每次列表请求有独立序号和取消信号；新请求取消旧请求，即使旧结果晚到，也不能覆盖当前筛选列表或将已遮蔽身份重新显示。一次读取超过 60 秒会超时退出并允许重试；取消浏览器请求不表示后端扫描已经停止。
- 初次失败后的重试重新获取工作区身份。身份一旦建立，普通重试不重新采纳恢复数据库后的身份，以保留旧窗口写入保护。
- 无搜索结果时禁用入口，并提供“清除筛选”。重试保留查询，清除操作同时恢复全部病例及患者列表；不把零匹配当成零病例。
- 顶部入口与行按钮都从当前筛选集合取病例，并采用该病例的下一复核环节。读取期间的重复点击不会重复打开病例；病例级最后导航／取消保护继续由原有生命周期控制。
- 恢复后焦点移至更新后的索引说明，清除筛选后焦点移至列表状态。窄屏相关控件采用 44px 最小高度；不更改其他临床页面布局。

## 浏览器验证

2. 停止合成服务后点击工作台：页面保留，旧行消失，统计为“—”，中文提示和重试按钮可用。控制台仅见本次故障注入对应的读取错误，未见其他应用异常。
3. 在 390×844 核对恢复提示换行、入口与重试按钮高度 44px，页面宽度与视口均为 390px。宽病例表仅在自身容器中横向滚动。

5. 使用匹配病例编号再次断线／恢复，顶部入口随后打开该合成病例的下一环节“模板编辑”，出现真实合成波形与 1503 条正常搏记录。没有进行类型修订或审核。
