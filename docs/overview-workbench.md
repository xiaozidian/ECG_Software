# 医院总览与房颤工作台

对应用户提供的总览、三类右键菜单、房颤工作台及彩色波形叠加截图。功能与数据语义对齐，不声称复现分规私有算法或获得临床验证。

## 图表与统计口径

| 组件 | 含义与实现 |
| --- | --- |
| 全程 RR 直方图 | 横轴 RR（25 ms 分箱），纵轴心搏数；最后一箱为 ≥2600 ms，计数不丢弃长间期。点击柱形打开对应心搏图条。 |
| 全程 R/R 直方图 | 当前 RR / 前一 RR ×100%，2.5% 分箱，最后一箱 ≥300%。无效或伪差不跨越拼接。 |
| 优化显示（对数） | 柱高按 log10(n+1) 映射，零计数仍为零；标签保留实际次数，不修改分箱或原数据。 |
| 全程／小时心率趋势 | 基于当前逐搏 RR 的 60000/RR（bpm）。高密度时保留每个像素内的最小／最大值，而不是一分钟平均值连线。 |
| 全程／小时 RR 时间散点 | 横轴记录时间，纵轴 RR（ms），每个有效 RR 贡献一个点。不是 RR(i) 对 RR(i+1) 的 Lorenz 图。 |
| Lorenz 散点 | 横轴 RR(i)、纵轴 RR(i+1)；可按 N/S/V、全程、小时和连续正常 NN 配对筛选。排除伪差邻接，不把两个不相邻的正常搏硬拼成 NN。 |
| 连续波形 | 与图表共用当前位置，可查看逐搏类型、心率、RR、时间／幅度坐标。底部单导联导航显示当前窗口前后波形。 |
| 结论统计 | 总心搏估算保留源报告值；当前有效总数排除 X，伪差／V／S 比例分母为当前全部标记数。长 RR 候选按可配置停搏阈值统计，不称为确诊停搏。 |

图表点击定位，拖动建立时间或点选区，方向键移动窗口，Shift+方向键移动一分钟。右键／Shift+F10／标题“操作”均可进入菜单；菜单支持上下键及 Escape。波形本身沿用滚轮缩放、增益和全屏交互。

右栏顺序为“散点图复核 → 结论统计 → 当前窗口／人工标注”，视觉与 DOM 阅读顺序一致。复核区左侧片段列表内部滚动，右侧散点画布填满控件下方的图框；窗口变化或展开键盘范围选择时按容器尺寸重绘。点云不会被自动缩放到铺满坐标轴，0–2000／3000／5000 ms 的范围及已选心搏保持不变。

## 三类右键菜单

### RR 时间散点：房颤／房扑

添加 AF 或 AFL、删除当前段、移除选区重叠部分、移除所有段、标记全程 AF/AFL、重分析 RR 候选、进入房颤编辑与分析。跨越选区的片段会切分保留外侧部分，不删除原始信号。

分析工作台含全程 RR、选中时段 Lorenz、可点击的片段表、当前小时的四个 15 分钟 RR 面板、原始波形。可编辑开始／结束秒数、类型、待复核／医生确认／已排除及备注；保存前确认，保存后可撤销／重做。确认段不允许互相重叠，以免负荷重复累计。短记录的面板不填充虚构时间。

1280 宽度采用 Lorenz、片段列表、四个时段并列的紧凑布局，片段编辑按需展开；首屏可对照 II／V1，查看完整 V5 需向下滚动。1920 屏幕保留较大的散点与四行时段，并可同时查看三导联。

“重分析房颤”使用 `rr-irregularity-v1`：30 秒不重叠窗口、至少 20 个有效搏及 25 秒覆盖、至少 90% 正常有效间期、RR 300–2000 ms、CV ≥0.12、归一化 RMSSD ≥0.14、转折率 0.45–0.85。结果全部为待复核 AF 候选；不识别 P 波，也不自动识别 AFL。重新分析只替换本规则生成的候选，保留人工及源片段并避开其区间。

### Lorenz：心搏与显示

- 框选／自由圈选／单点定位，匹配全集合，不只匹配抽样散点。
- 改型、改前／后一心搏、手动批量 QRS、自动向前／向后插入候选：调用共用心搏编辑器，展示影响预览，用户确认后才提交。多选的前／后心搏按全部锚点计算并去重，记录边界没有邻搏的锚点不生成目标；预览显示实际影响数。
- 排除房颤／房扑：切除选中各 RR 对应的独立时间区间，不删除两个离散点之间的整段时间。
- N、S、V、小时、NN、RR 六种图型；0–2000／3000／5000 ms 范围；四档点大小和辅助线开关。

### 心率趋势：图条与测量

| 菜单项 | 实际行为 |
| --- | --- |

| 即时打印 | 三／十二导联 A4 图条预览，明确标为自适应幅度，非标准走纸比例。不改变最终报告的纸张设置。 |
| 插入心搏 | 共用插搏预览。 |
| 选择起始位置 | 点击另一时间点确定结束，所有时间图联动。 |
| 删除前面／后面区段 | 仅在覆盖层删除选区之前／之后的心搏标记；批量预览后确认，可撤销；绝不裁剪 DATA。 |

| 设置选项 | 共用心搏分析设置。 |

## 彩色波形叠加图是什么

截图的黑底绿／黄／红图，结合横轴时间和多导联外形，属于 **R 峰对齐波形叠加密度图**（superimposition density），并非 Lorenz 散点。每个心搏按 R 峰对齐，显示前后各 1 秒；纵轴为幅度，颜色表示同一时间—幅度格中的重复次数，绿低、黄中、红高。

本实现按当前类别或模板的全部完整心搏计数，用 10 ms ×128 幅度格统计；R 前 −200 至 −100 ms 的固定基线被减去，不对每搏独立缩放。幅度范围由最多 1000 搏的确定性样本估计，**计数仍使用全部心搏**。页面列出边界不足而跳过的心搏数及超出幅度范围的采样点数。框选命中同一设备标度中的波形点，返回精确心搏索引；下方最多 24 搏预览只是预览，不是密度样本量。创建模板仍遵守现有单次 500 搏限制。

参考：[Hillrom Holter 操作手册中的叠加审阅](https://www.hillrom.com/content/dam/hillrom-aem/us/en/sap-documents/LIT/9515-/9515-213-70-ENGLITPDF.pdf)。截图不足以确定原厂的全部归一化／滤波参数，本实现不宣称与其颜色数值逐像素一致。

## 安全、版本与测试

本地 `rhythm_reviews` 保存在 SQLite，与逐搏修订版本共同乐观锁校验；修改使已有报告审核依据过期。删除片段后不让旧 AF 心搏标签重新生成被删除的片段；片段状态同步报告事件。Demo 用独立 localStorage，浏览器支持时使用 Web Locks 串行保存，仍需版本匹配。公开数据继续是原单病例 10 分钟片段，更新界面不增加病例数据。

新增回归覆盖相邻 RR 语义、对数图底层计数、规则候选反例、反复切分、片段版本／撤销／重做、源片段权威性、Python／JavaScript 密度与 STRIP 事件一致性、API 校验及构建资源同步。它们是功能回归，**不是临床灵敏度、特异度或注册验证**。房颤确认需要专业人员结合 ECG 证据；参见 [ESC 2024 房颤指南](https://www.escardio.org/guidelines/clinical-practice-guidelines/all-esc-practice-guidelines/atrial-fibrillation/)。
